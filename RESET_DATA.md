# 🔄 Сброс данных приложения

## 📋 Проблема: не видно изменений

Если вы не видите изменения в предварительном просмотре (например, блок "Кабинет" или кнопку "Подключиться к конференции"), это может быть связано с тем, что старые данные в localStorage не содержат новые поля.

## ✅ Решение: кнопка сброса данных

В правом нижнем углу экрана появилась кнопка **"Сброс данных"** 🗑️

### Как использовать:

1. **Найдите кнопку** в правом нижнем углу экрана (красная кнопка с иконкой корзины)

2. **Нажмите на кнопку** - появится окно подтверждения

3. **Подтвердите сброс** - нажмите "Сбросить"

4. **Дождитесь перезагрузки** - страница автоматически перезагрузится

5. **Войдите снова** - используйте демо-аккаунты:
   - Админ: `admin@vks.local` / `admin123`
   - Модератор: `sidorov@vks.local` / `mod123`
   - Пользователь: `ivanov@vks.local` / `user123`

6. **Проверьте изменения** - теперь должны быть видны все новые функции:
   - ✅ Блок "Кабинет" в дополнительной информации
   - ✅ Кнопка "Подключиться к конференции" (всегда видна)
   - ✅ Место проведения с подписью
   - ✅ Тёмная тема
   - ✅ Шаблоны
   - ✅ Теги
   - ✅ И другие новые функции

## 🎯 Что происходит при сбросе

При сбросе данных удаляются:
- ✅ Пользователи
- ✅ Конференции
- ✅ Уведомления
- ✅ Настройки
- ✅ Шаблоны
- ✅ Теги
- ✅ Вложения
- ✅ История изменений

После сброса автоматически загружаются **демо-данные** с новыми полями и функциями.

## 🔍 Альтернативные способы сброса

### Способ 1: Через консоль браузера

1. Откройте приложение в браузере
2. Нажмите `F12` (откроется консоль разработчика)
3. Перейдите на вкладку **Console**
4. Введите команду:
   ```javascript
   localStorage.clear()
   ```
5. Обновите страницу (`F5` или `Ctrl+R`)
6. Войдите снова

### Способ 2: Через DevTools

1. Откройте приложение в браузере
2. Нажмите `F12`
3. Перейдите на вкладку **Application** (или **Storage**)
4. В左侧菜单 выберите **Local Storage** → **ваш домен**
5. Нажмите **Clear all** (очистить всё)
6. Обновите страницу

### Способ 3: Приватный режим

1. Откройте браузер в режиме инкогнито/приватности
2. Перейдите по ссылке на приложение
3. Войдите в систему (демо-данные загрузятся с новыми полями)

## 📊 Проверка данных

Чтобы убедиться, что данные загружены правильно:

1. Откройте консоль браузера (`F12`)
2. Введите команду:
   ```javascript
   JSON.parse(localStorage.getItem('vks_meetings'))
   ```
3. Проверьте, что у каждой конференции есть поле `room`:
   ```javascript
   {
     id: "...",
     title: "Обзор проекта Q4",
     room: "Конференц-зал А",  // ← Это поле должно быть!
     // ... другие поля
   }
   ```

## 💡 Почему это происходит?

Когда вы впервые открываете приложение, загружаются демо-данные и сохраняются в localStorage. Если вы уже открывали приложение до добавления новых функций, старые данные не содержат новых полей (например, `room`, `isFavorite`, `tags` и т.д.).

Сброс данных удаляет старые данные и загружает новые демо-данные с актуальными полями.

## ✅ Чек-лист после сброса

После сброса данных вы должны увидеть:

- [ ] Кнопка "Сброс данных" в правом нижнем углу
- [ ] Блок "Следующая конференция" с полной информацией
- [ ] Блок "Кабинет" в дополнительной информации
- [ ] Кнопка "Подключиться к конференции" (всегда видна)
- [ ] Место проведения с подписью (📍 Кабинет / 🌐 Онлайн)
- [ ] Список конференций на сегодня с кабинетами
- [ ] Новые функции: тёмная тема, шаблоны, теги и т.д.

## 🎉 Готово!

После сброса данных все новые функции должны быть видны в предварительном просмотре!
