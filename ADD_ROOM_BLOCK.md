## 📍 Где отображается кабинет

### 1. В верхней части (основная информация)
```
📍 Место проведения
Конференц-зал А
📍 Кабинет / Переговорная
```

### 2. В дополнительной информации (НОВОЕ!)
```
🚪 Кабинет
📍 Конференц-зал А
```

Или если онлайн:
```
🚪 Кабинет
🌐 Онлайн
```

## 💡 Преимущества

✅ **Двойное отображение** - кабинет виден и в основной, и в дополнительной информации  
✅ **Более заметно** - отдельная карточка с иконкой двери 🚪  
✅ **Цветовая индикация** - оранжевый для кабинета, синий для онлайн  
✅ **Удобно для модераторов** - сразу видно где проходит ВКС  

## 🔍 Детали реализации

### Карточка "Кабинет":
```tsx
<div>
  <p className="text-sm text-gray-600 font-medium flex items-center gap-1 mb-1">
    <i className="fas fa-door-open"></i> Кабинет
  </p>
  <p className="text-gray-800 font-semibold">
    {nextMeeting.room ? (
      <span className="text-orange-600">📍 {nextMeeting.room}</span>
    ) : (
      <span className="text-blue-600">🌐 Онлайн</span>
    )}
  </p>
</div>
```

### Особенности:
- Иконка двери (`fa-door-open`) для визуального отличия
- Оранжевый цвет для кабинета (как в основной информации)
- Синий цвет для онлайн встреч
- Жирный шрифт для лучшей читаемости
