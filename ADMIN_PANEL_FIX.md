## ❌ Проблема

В админ-панели в разделе "Конференции" кнопки не работали:
- ❌ Кнопка "Создать" не открывала форму
- ❌ Кнопка "Редактировать" не открывала форму редактирования
- ❌ Кнопка "Удалить" работала, но не было формы для создания

**Причина:** Отсутствовало модальное окно для формы создания/редактирования конференции.

---

## ✅ Решение

- ✅ **Название** (обязательное)
- ✅ **Описание** (необязательное)
- ✅ **Дата** (обязательное)
- ✅ **Комната** (необязательное)
- ✅ **Время начала** (обязательное)
- ✅ **Время окончания** (обязательное)

- ✅ **Приоритет** (низкий/средний/высокий)
- ✅ **Напоминание** (минуты)

## 📋 Как использовать

### Создание конференции:

1. Войдите как администратор (`admin` / `admin123`)
2. Перейдите в "Админ-панель"
3. Вкладка "Конференции"
4. Нажмите кнопку **"Создать"**
5. Заполните форму:
   - Название: "Совещание отдела"
   - Описание: "Обсуждение планов на квартал"
   - Дата: выберите дату
   - Комната: "Переговорная №3"
   - Время начала: 14:00
   - Время окончания: 15:00
   - Ссылка на ВКС: https://zoom.us/j/123456789
   - Приоритет: Высокий
   - Напоминание: 15 минут
6. Выберите участников (кликайте по именам)
7. Поставьте галочку "Приватная конференция" (если нужно)
8. Нажмите **"Создать"**

### Редактирование конференции:

1. Найдите конференцию в списке
2. Нажмите на иконку **✏️** (редактировать)
3. Измените нужные поля
4. Нажмите **"Сохранить"**

### Удаление конференции:

1. Найдите конференцию в списке
2. Нажмите на иконку **🗑️** (удалить)
3. Подтвердите удаление

### Изменение статуса:

1. Найдите конференцию в списке
2. В колонке "Статус" нажмите на выпадающий список
3. Выберите новый статус
4. Изменения сохраняются автоматически

```typescript
// Создание/редактирование конференции
const handleSaveMeeting = (e: React.FormEvent) => {
  e.preventDefault();
  if (editingMeeting) {
    updateMeeting({ ...meetingForm, id: editingMeeting.id });
  } else {
    addMeeting({ ...meetingForm, id: generateId(), organizerId: user.id });
  }
  setMeetings(getMeetings());
  setShowMeetingForm(false);
  setEditingMeeting(null);
  setMeetingForm(emptyMeeting);
};

// Редактирование конференции
const handleEditMeeting = (m: Meeting) => {
  setEditingMeeting(m);
  setMeetingForm(m);
  setShowMeetingForm(true);
};

// Удаление конференции
const handleDeleteMeeting = (id: string) => {
  if (confirm('Удалить конференцию?')) {
    deleteMeeting(id);
    setMeetings(getMeetings());
  }
};

// Изменение статуса
const handleStatusChange = (id: string, status: Meeting['status']) => {
  const meeting = meetings.find(m => m.id === id);
  if (meeting) {
    updateMeeting({ ...meeting, status });
    setMeetings(getMeetings());
  }
};
```
