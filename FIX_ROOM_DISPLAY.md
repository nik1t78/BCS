# ✅ Исправлено: Отображение кабинета на главной странице

## 📋 Проблема

На главной странице (Dashboard) не было понятно, где именно проходит видеоконференция - в кабинете или онлайн.

## 🔧 Что было исправлено

### 1. Блок "Следующая конференция"

**Было:**
```
📍 Место проведения
Переговорная №1
Кабинет/переговорная  ← показывалось только если указан кабинет
```

**Стало:**
```
📍 Место проведения
Переговорная №1
📍 Кабинет / Переговорная  ← всегда показывается с иконкой
```

Или если онлайн:
```
📍 Место проведения
Онлайн
🌐 Виртуальная встреча  ← всегда показывается с иконкой
```

### 2. Список конференций на сегодня

**Было:**
```
📍 Место: Переговорная №1
```

**Стало:**
```
📍 Кабинет: Переговорная №1  ← если указан кабинет
```

Или:
```
🌐 Онлайн  ← если не указан кабинет
```
