

## Обновление 2026-11-11: Центр управления ВКС

Добавлен лениво загружаемый раздел «Центр управления»:
- обзор заявок и активных залов;
- быстрая заявка на проведение конференции;
- список заявок и согласование администраторами/модераторами;
- просмотр оснащения залов из существующего поля rooms.equipment;
- рабочие переходы к расписанию, созданию ВКС и управлению залами;
- помощник организатора на встроенных правилах (не является подключённой LLM и не отправляет данные наружу);
- просмотр журнала действий для администратора (использует существующий audit API).

Backend: добавлены таблица meeting_approval_requests, модель и API GET/POST /api/approvals, PATCH /api/approvals/{id}/review. Все маршруты требуют Sanctum-аутентификацию; решение по заявке доступно только admin/moderator. Действия по созданию и рассмотрению заявок записываются в существующий audit_logs.

Скорость: новый раздел подключён через React.lazy, поэтому его код не загружается до открытия страницы. Тяжёлые зависимости не добавлялись; список заявок ограничен последними 100 записями, журнал в интерфейсе ограничен 50 строками.

Ограничения текущего этапа: QR-регистрация, базовая аналитика и аудит уже были в исходном проекте — они не дублировались. Оснащение пока читается из карточек залов и редактируется через существующую админ-панель. Помощник работает по локальным сценариям; для настоящей генеративной ИИ-модели требуется отдельно настроить корпоративный API/локальную модель и правила хранения данных. Реальная сборка Docker/React и интеграционные тесты требуют запуска в окружении проекта.

## Установка обновления

1. Сделайте резервную копию БД и папки проекта.
2. Распакуйте архив в отдельную тестовую папку или подготовьте копию рабочей папки.
3. Сохраните действующий `.env` и Docker volumes; не удаляйте их.
4. Пересоберите фронтенд и backend: `docker compose up -d --build`.
5. Примените миграции: `docker compose exec backend php artisan migrate --force`.
6. Проверьте API `/api/approvals` под авторизованным пользователем и откройте «Центр управления».
