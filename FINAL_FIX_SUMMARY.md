## ✅ Что было исправлено

### 1. Уведомления при создании конференции

**Проблема:** При создании конференции уведомления не отправлялись участникам

**Решение:** Добавлено автоматическое создание уведомлений для всех участников

**Код:**
```typescript
// При создании новой конференции
formData.participants.forEach(participantId => {
  if (participantId !== user.id) {
    addNotification({
      id: generateId(),
      userId: participantId,
      meetingId: newMeetingId,
      message: `👤 Вас добавили в конференцию "${formData.title}"`,
      type: 'user-added',
      timestamp: new Date().toISOString(),
      read: false,
    });
  }
});
```

### 2. Теги в конференциях

**Проблема:** Теги не были привязаны к конференциям

**Решение:** Создан компонент `TagsSelector` для выбора тегов при создании конференции

**Новый компонент:** `src/components/TagsSelector.tsx`
- Отображает все доступные теги
- Позволяет выбирать несколько тегов
- Сохраняет выбранные теги в конференции
- Показывает количество выбранных тегов

## 🎯 Как проверить работу

### Проверка уведомлений:

1. **Войдите как администратор** (`admin` / `admin123`)
2. Перейдите в **"Мои конференции"**
3. Нажмите **"Создать конференцию"**
4. Заполните форму:
   - Название: "Тестовая конференция"
   - Дата: сегодня
   - Время: через 1 час
   - **Выберите 2-3 участников** из списка
5. Нажмите **"Создать"**
6. **Выйдите из системы**
7. **Войдите как один из участников** (например, `ivanov` / `user123`)
8. Перейдите в **"Уведомления"**
9. **Должно быть уведомление:** "👤 Вас добавили в конференцию 'Тестовая конференция'"

### Проверка тегов:

1. **Войдите как администратор**
2. Перейдите в **"Теги"**
3. Создайте несколько тегов:
   - "Важное" (красный цвет)
   - "Обучение" (синий цвет)
   - "Клиенты" (зелёный цвет)
4. Перейдите в **"Мои конференции"**
5. Нажмите **"Создать конференцию"**
6. В форме найдите раздел **"Теги"**
7. **Выберите несколько тегов** из списка
8. Создайте конференцию
9. **Теги должны сохраниться** и отображаться в конференции
