## 🏠 Вариант 1: Локальная сеть (LAN)

### Шаг 1: Подготовка сервера

**Требования к компьютеру-серверу:**
- Windows 10/11 или Linux
- Минимум 4 GB RAM
- Минимум 20 GB свободного места
- Стабильное интернет-соединение
- Статический IP адрес (желательно)

**Установка необходимого ПО:**

```powershell
# 1. Установите Node.js (если еще не установлен)
# Скачайте с https://nodejs.org/ (версия 20 LTS)

# 2. Проверьте установку
node --version
npm --version

# 3. Установите Git (если еще не установлен)
# Скачайте с https://git-scm.com/
```

### Шаг 2: Настройка проекта

```powershell
# 1. Перейдите в папку проекта
cd D:\BCS

# 2. Установите зависимости (если еще не установлены)
npm install

# 3. Соберите проект для production
npm run build
```

### Шаг 3: Установка простого веб-сервера

**Вариант A: Использовать встроенный сервер Vite (для тестирования)**

```powershell
# Запустите сервер на всех интерфейсах
npm run dev -- --host 0.0.0.0 --port 3000
```

**Вариант B: Использовать serve (рекомендуется для production)**

```powershell
# 1. Установите serve глобально
npm install -g serve

# 2. Запустите сервер
serve -s dist -l 3000
```

**Вариант C: Использовать Python (если установлен)**

```powershell
# Перейдите в папку dist
cd dist

# Запустите Python сервер
python -m http.server 3000
```

### Шаг 4: Настройка firewall

**Windows:**

```powershell
# Откройте PowerShell от имени администратора

# Разрешите порт 3000
netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000

# Или через GUI:
# 1. Панель управления → Система и безопасность → Брандмауэр Windows
# 2. Дополнительные параметры → Правила для входящих подключений
# 3. Создать правило → Для порта → TCP → 3000 → Разрешить
```

**Linux (Ubuntu/Debian):**

```bash
# Откройте порт 3000
sudo ufw allow 3000/tcp
sudo ufw reload
```

### Шаг 5: Узнайте IP адрес сервера

**Windows:**

```powershell
# В командной строке
ipconfig

# Найдите строку "IPv4-адрес"
# Например: 192.168.1.100
```

**Linux:**

```bash
# В терминале
ip addr show

# Или
hostname -I
```

### Шаг 6: Доступ для сотрудников

**Сотрудники открывают в браузере:**

```
http://192.168.1.100:3000
```

Где `192.168.1.100` - IP адрес вашего сервера.

### Шаг 7: Создание первого администратора

1. Откройте `http://192.168.1.100:3000`
2. Зарегистрируйтесь с логином `admin`
3. Откройте консоль браузера (F12)
4. Выполните команду:

```javascript
// Получите всех пользователей
const users = JSON.parse(localStorage.getItem('vks_users'));

// Найдите вашего пользователя
const admin = users.find(u => u.login === 'admin');

// Назначьте роль администратора
admin.role = 'admin';

// Сохраните изменения
localStorage.setItem('vks_users', JSON.stringify(users));

// Обновите страницу
location.reload();
```

5. Теперь вы администратор!

4. Нажмите "Добавить пользователя"
5. Заполните форму:
   - ФИО: Иванов Иван Иванович
   - Логин: ivanov
   - Пароль: Ivanov123!

   - Отдел: Разработка
6. Нажмите "Создать"

**Или через регистрацию:**

1. Дайте сотруднику адрес: `http://192.168.1.100:3000`
2. Сотрудник регистрируется сам
3. Вы назначаете роль через админ-панель

## 🌐 Вариант 2: Виртуальный сервер (VPS)

### Шаг 1: Аренда VPS

**Рекомендуемые провайдеры:**

| Провайдер | Минимальная цена | Характеристики |
|-----------|------------------|----------------|
| Timeweb | 199 руб/мес | 1 CPU, 1 GB RAM, 20 GB SSD |
| Beget | 199 руб/мес | 1 CPU, 1 GB RAM, 15 GB SSD |
| Reg.ru | 250 руб/мес | 1 CPU, 2 GB RAM, 30 GB SSD |
| Selectel | 300 руб/мес | 1 CPU, 2 GB RAM, 40 GB SSD |

**Рекомендуемые характеристики:**
- OS: Ubuntu 22.04 LTS
- CPU: 2 vCPU
- RAM: 2 GB
- Disk: 40 GB SSD
- Traffic: Безлимитный

### Шаг 2: Подключение к серверу

```bash
# Подключитесь по SSH
ssh root@your_server_ip

# Или используйте пароль
ssh root@your_server_ip
```

### Шаг 3: Установка необходимого ПО

```bash
# Обновите систему
sudo apt update && sudo apt upgrade -y

# Установите Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Установите Git
sudo apt install -y git

# Установите Nginx
sudo apt install -y nginx

# Установите PM2 (менеджер процессов)
sudo npm install -g pm2
```

### Шаг 4: Загрузка проекта

```bash
# Создайте папку для проекта
sudo mkdir -p /var/www/vks-schedule
cd /var/www/vks-schedule

# Клонируйте репозиторий (или загрузите файлы через SCP)
sudo git clone https://github.com/your-username/vks-schedule.git .

# Или загрузите через SCP с локального компьютера
# На локальном компьютере:
scp -r D:\BCS\* root@your_server_ip:/var/www/vks-schedule/
```

### Шаг 5: Сборка проекта

```bash
# Перейдите в папку проекта
cd /var/www/vks-schedule

# Установите зависимости
sudo npm install

# Соберите проект
sudo npm run build
```

### Шаг 6: Настройка Nginx

```bash
# Создайте конфигурацию Nginx
sudo nano /etc/nginx/sites-available/vks-schedule
```

**Вставьте следующий код:**

```nginx
server {
    listen 80;
    server_name your_domain.com;  # Или IP адрес сервера

    root /var/www/vks-schedule/dist;
    index index.html;

    # Кэширование статических файлов
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # SPA routing
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Безопасность
    location ~ /\.ht {
        deny all;
    }
}
```

**Активируйте сайт:**

```bash
# Создайте символическую ссылку
sudo ln -s /etc/nginx/sites-available/vks-schedule /etc/nginx/sites-enabled/

# Проверьте конфигурацию
sudo nginx -t

# Перезапустите Nginx
sudo systemctl restart nginx
```

### Шаг 7: Запуск с PM2

```bash
# Установите serve глобально
sudo npm install -g serve

# Запустите сервер через PM2
pm2 start "serve -s /var/www/vks-schedule/dist -l 3000" --name vks-schedule

# Настройте автозапуск
pm2 startup
pm2 save
```

### Шаг 8: Настройка firewall

```bash
# Откройте порты
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS (если будет)
sudo ufw enable

# Проверьте статус
sudo ufw status
```

### Шаг 9: Настройка домена (опционально)

**Купите домен:**
- reg.ru
- nic.ru
- beget.com

**Настройте DNS:**

```
Тип: A
Имя: @ (или vks.yourdomain.com)
Значение: IP адрес вашего сервера
TTL: 3600
```

**Получите SSL сертификат:**

```bash
# Установите Certbot
sudo apt install certbot python3-certbot-nginx

# Получите сертификат
sudo certbot --nginx -d your_domain.com

# Автообновление
sudo certbot renew --dry-run
```

## 🆘 Решение проблем

### Проблема: Сотрудники не могут подключиться

**Решение:**

```powershell
# 1. Проверьте что сервер запущен
pm2 status

# 2. Проверьте firewall
netsh advfirewall firewall show rule name="ВКС Расписание"

# 3. Проверьте IP адрес
ipconfig

# 4. Проверьте доступность порта
Test-NetConnection -ComputerName 192.168.1.100 -Port 3000
```

### Проблема: Медленная работа

**Решение:**

```bash
# 1. Проверьте нагрузку
top

# 2. Проверьте память
free -h

# 3. Проверьте диск
df -h

# 4. Перезапустите сервер
pm2 restart vks-schedule
```
