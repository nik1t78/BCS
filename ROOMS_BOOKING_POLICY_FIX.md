# Изменение логики «Свободные залы»

- Убрана надпись «Закрыто (нерабочий день)» с главной страницы.
- Выходные и праздничные отметки в графике зала больше не блокируют выбор свободного времени в виджете.
- Для даты, отмеченной закрытой, свободные интервалы рассчитываются по фактическим встречам в стандартном диапазоне 08:00–20:00.
- Существующие встречи остаются занятыми и некликабельными; свободные блоки можно выбрать для создания ВКС.
- Для обычных дней сохраняются индивидуальные часы зала.
- Файлы и данные базы данных не удалялись.

Проверка в этом окружении ограничена проверкой исходного кода: интеграционный запуск с MySQL/Docker и браузерный тест требуют развернутого окружения проекта.
