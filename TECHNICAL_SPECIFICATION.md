# 📋 Техническое задание (ТЗ)

## ВКС Расписание - Система управления видеоконференциями

---

## 1. 📌 Общая информация

**Название проекта**: ВКС Расписание  
**Тип приложения**: Веб-приложение (SPA + REST API)  
**Назначение**: Управление расписанием видеоконференций с системой авторизации, уведомлениями и админ-панелью  
**Целевая аудитория**: Организации любого размера для планирования и проведения видеоконференций

---

## 2. 🎯 Цели проекта

### Основные цели:
- ✅ Предоставить удобный инструмент для планирования видеоконференций
- ✅ Реализовать систему регистрации и авторизации с ролевой моделью
- ✅ Обеспечить автоматические уведомления о предстоящих конференциях
- ✅ Создать админ-панель для управления пользователями и конференциями
- ✅ Обеспечить доступ из локальной сети и интернета

### Дополнительные цели:
- ✅ Экспорт расписания в различные форматы
- ✅ Статистика и аналитика конференций
- ✅ Адаптивный дизайн для всех устройств
- ✅ Интуитивно понятный интерфейс с подсказками

---

## 3. 🏗️ Архитектура системы

### Frontend:
- **Технологии**: React 18, TypeScript, Tailwind CSS, Vite
- **Тип**: Single Page Application (SPA)
- **Хранение данных**: LocalStorage (для локальной версии)
- **Адаптивность**: Mobile-first дизайн

### Backend:
- **Технологии**: Laravel 10, PHP 8.2
- **База данных**: MySQL 8.0
- **Кэш**: Redis
- **Аутентификация**: Laravel Sanctum (API токены)
- **Очереди**: Redis Queue

### Infrastructure:
- **Контейнеризация**: Docker, Docker Compose
- **Web Server**: Nginx (reverse proxy)
- **Email testing**: MailHog
- **Scheduler**: Laravel Scheduler (cron)

## 5. 📊 Функциональные требования

### 5.1. Авторизация и безопасность (4 функции)
1. **Регистрация пользователей**
   - Создание нового аккаунта
   - Валидация email (уникальность)
   - Хеширование паролей (bcrypt)
   - Минимальная длина пароля: 6 символов

2. **Вход в систему**
   - Аутентификация по email/пароль
   - Проверка статуса аккаунта (активен/заблокирован)
   - Генерация API токена (Sanctum)
   - Запись времени последнего входа

3. **Выход из системы**
   - Удаление токена доступа
   - Очистка сессии

4. **Автоматическая блокировка**
   - Блокировка аккаунта администратором/модератором
   - Запрет входа для заблокированных пользователей

### 5.2. Управление профилем (4 функции)
5. **Просмотр профиля**
   - Отображение личных данных (ФИО, email, телефон, отдел, должность)
   - Информация об аккаунте (дата регистрации, последний вход, роль)

6. **Редактирование профиля**
   - Изменение имени, email, телефона, отдела, должности
   - Валидация данных

7. **Смена пароля**
   - Проверка текущего пароля
   - Установка нового пароля
   - Минимальная длина: 6 символов

8. **Настройки уведомлений**
   - Звуковые уведомления (вкл/выкл)
   - Браузерные уведомления (вкл/выкл)
   - Время напоминания по умолчанию (5-1440 мин)
   - Рабочие часы (начало/конец)
   - Часовой пояс

### 5.3. Управление конференциями (8 функций)
9. **Создание конференции**
   - Обязательные поля: название, дата, время начала/окончания
   - Опциональные поля: описание, комната, ссылка на ВКС
   - Приоритет: низкий/средний/высокий
   - Напоминание за N минут (5-1440)
   - Повторение: не повторять/ежедневно/еженедельно/ежемесячно
   - Участники: пользователи системы + внешние email
   - Приватность: публичная/приватная

10. **Просмотр списка конференций**
    - Фильтры: все/организованные/участие/ближайшие
    - Поиск по названию/комнате
    - Сортировка по дате и времени

11. **Просмотр деталей конференции**
    - Полная информация о конференции
    - Список участников
    - Организатор
    - Ссылка для подключения

12. **Редактирование конференции**
    - Изменение всех полей
    - Доступ: организатор или админ

13. **Удаление конференции**
    - Доступ: организатор или админ
    - Подтверждение удаления

14. **Изменение статуса конференции**
    - Статусы: запланирована/идёт/завершена/отменена
    - Доступ: организатор, админ, модератор

15. **Приватные конференции**
    - Видны только участникам и организатору
    - Не отображаются в общем списке

16. **Повторяющиеся конференции**
    - Автоматическое создание серий
    - Типы: ежедневно/еженедельно/ежемесячно

### 5.4. Расписание и календарь (5 функций)
17. **Просмотр по дням**
    - Список конференций на конкретный день
    - Хронологический порядок

18. **Просмотр по неделям**
    - Сетка на 7 дней (Пн-Вс)
    - Цветовая кодировка по приоритету

19. **Просмотр по месяцам**
    - Календарная сетка на месяц
    - Количество конференций на каждый день

20. **Фильтры расписания**
    - Все/мои/сегодня/ближайшие
    - Комбинация с поиском

21. **Экспорт расписания**
    - Форматы: ICS (календарь), JSON, CSV (Excel)
    - Экспорт только своих конференций

### 5.5. Система уведомлений (10 функций)
22. **Напоминания о конференциях**
    - Уведомление за N минут до начала
    - Проверка каждую минуту (scheduler)
    - Звуковой сигнал + браузерное уведомление

23. **Уведомление о начале конференции**
    - Срабатывает когда start_time == current_time
    - Тип уведомления: starting

24. **Уведомление о добавлении в конференцию**
    - Отправляется при создании/обновлении конференции
    - Тип уведомления: user-added

25. **Список уведомлений**
    - Фильтры: все/непрочитанные/прочитанные
    - Сортировка по дате (новые сверху)

26. **Отметка прочитанным**
    - Отдельное уведомление
    - Все уведомления сразу

27. **Очистка уведомлений**
    - Удаление всех уведомлений
    - Подтверждение действия

28. **Счётчик непрочитанных**
    - Бейдж в шапке сайта
    - Обновление каждые 30 секунд

29. **Браузерные уведомления (Push)**
    - Системные уведомления браузера
    - Работают даже когда вкладка не активна
    - Требуют разрешения пользователя

30. **Звуковые уведомления**
    - Звуковой сигнал при уведомлении
    - Настройка вкл/выкл в профиле

31. **Автоматическая проверка**
    - Scheduler проверяет каждую минуту
    - Команда: `php artisan meetings:send-reminders`

### 5.6. Управление пользователями (7 функций)
32. **Список пользователей**
    - Поиск по имени/email/отделу
    - Фильтр по роли
    - Отображение статуса (активен/заблокирован)

33. **Создание пользователя**
    - Доступ: только админ
    - Поля: имя, email, пароль, роль, телефон, отдел, должность
    - Валидация уникальности email

34. **Редактирование пользователя**
    - Доступ: админ (любой пользователь), модератор (только просмотр)
    - Изменение всех полей

35. **Удаление пользователя**
    - Доступ: только админ
    - Нельзя удалить себя
    - Подтверждение удаления

36. **Изменение роли**
    - Доступ: только админ
    - Роли: admin/moderator/user
    - Мгновенное применение

37. **Блокировка/разблокировка**
    - Доступ: админ, модератор
    - Нельзя заблокировать себя
    - Запрет входа для заблокированных

38. **Смена пароля пользователя**
    - Доступ: только админ
    - Модальное окно с вводом нового пароля
    - Подтверждение пароля
    - Логирование действия

### 5.7. Статистика и аналитика (4 функции)
39. **Статистика конференций**
    - Всего конференций
    - Запланированные/в процессе/завершённые/отменённые
    - На этой неделе
    - Высокий приоритет

40. **Статистика пользователей**
    - Всего пользователей
    - Активных
    - Администраторов/модераторов/обычных
    - Новых за месяц

41. **Дашборд**
    - Приветствие с именем
    - Текущая дата и время
    - Статистика на сегодня
    - Следующая конференция с обратным отсчётом
    - Список конференций на сегодня

42. **Расширенная аналитика**
    - Средняя длительность конференций
    - Самый активный день недели
    - Распределение по статусам (визуальные прогресс-бары)
    - Быстрые действия

### 5.8. Интерфейс и UX (5 функций)
43. **Интерактивный тур**
    - 6 экранов с описанием функций
    - Показывается при первом входе
    - Навигация: далее/пропустить
    - Хранение в LocalStorage

44. **Подсказки (Tooltips)**
    - Всплывающие подсказки на кнопках
    - Позиции: сверху/снизу/слева/справа
    - Триггер: наведение мыши

45. **Адаптивный дизайн**
    - Mobile: < 768px
    - Tablet: 768px - 1024px
    - Desktop: > 1024px

    - Сворачиваемый сайдбар

46. **Анимации**
    - Fade in/out
    - Slide up/down
    - Scale
    - Pulse (для уведомлений)

47. **Экспорт данных**
    - ICS для календарей
    - JSON для программной обработки
    - CSV для Excel

### 5.9. Поиск и фильтрация (4 функции)
48. **Глобальный поиск**
    - Поиск по названию, описанию, комнате
    - Real-time фильтрация

49. **Фильтры по статусу**
    - Все/запланированные/идут/завершённые/отменённые

50. **Фильтры по дате**
    - Сегодня/неделя/месяц/произвольный диапазон

51. **Фильтры по участникам**
    - Поиск конференций с определёнными участниками

## 6. 🗄️ Структура базы данных

### Таблица: users
```sql
- id (BIGINT, PRIMARY KEY)
- name (VARCHAR 255)
- email (VARCHAR 255, UNIQUE)
- password (VARCHAR 255, hashed)
- role (ENUM: admin, moderator, user)
- phone (VARCHAR 20, nullable)
- department (VARCHAR 255, nullable)
- position (VARCHAR 255, nullable)
- is_active (BOOLEAN, default: true)
- last_login (TIMESTAMP, nullable)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

### Таблица: meetings
```sql
- id (BIGINT, PRIMARY KEY)
- title (VARCHAR 255)
- description (TEXT, nullable)
- date (DATE)
- start_time (TIME)
- end_time (TIME)
- organizer_id (BIGINT, FOREIGN KEY → users.id)
- participants (JSON, array of user IDs)
- participant_emails (JSON, array of emails)
- link (VARCHAR 500, nullable)
- room (VARCHAR 255, nullable)
- status (ENUM: scheduled, in-progress, completed, cancelled)
- reminder_minutes (INT, default: 15)
- recurring (ENUM: none, daily, weekly, monthly)
- priority (ENUM: low, medium, high)
- is_private (BOOLEAN, default: false)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

### Таблица: notifications
```sql
- id (BIGINT, PRIMARY KEY)
- user_id (BIGINT, FOREIGN KEY → users.id)
- meeting_id (BIGINT, FOREIGN KEY → meetings.id, nullable)
- message (TEXT)
- type (ENUM: reminder, starting, info, warning, user-added)
- read (BOOLEAN, default: false)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

### Таблица: user_settings
```sql
- id (BIGINT, PRIMARY KEY)
- user_id (BIGINT, UNIQUE, FOREIGN KEY → users.id)
- sound_enabled (BOOLEAN, default: true)
- browser_notifications (BOOLEAN, default: true)
- default_reminder_minutes (INT, default: 15)
- work_hours_start (TIME, default: 09:00:00)
- work_hours_end (TIME, default: 18:00:00)
- timezone (VARCHAR 50, default: Europe/Moscow)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
```

## 7. 📡 API Endpoints

### Авторизация
```
POST   /api/auth/register          # Регистрация
POST   /api/auth/login             # Вход
POST   /api/auth/logout            # Выход
GET    /api/auth/user              # Текущий пользователь
```

### Конференции
```
GET    /api/meetings               # Список конференций
POST   /api/meetings               # Создать конференцию
GET    /api/meetings/{id}          # Получить конференцию
PUT    /api/meetings/{id}          # Обновить конференцию
DELETE /api/meetings/{id}          # Удалить конференцию
GET    /api/meetings-stats         # Статистика конференций
```

### Уведомления
```
GET    /api/notifications              # Список уведомлений
PUT    /api/notifications/{id}/read    # Отметить прочитанным
PUT    /api/notifications/read-all     # Прочитать все
DELETE /api/notifications/clear        # Очистить все
GET    /api/notifications/unread-count # Количество непрочитанных
```

### Профиль и настройки
```
PUT    /api/profile                    # Обновить профиль
POST   /api/profile/change-password    # Сменить пароль
GET    /api/settings                   # Получить настройки
PUT    /api/settings                   # Обновить настройки
```

### Админ-панель
```
GET    /api/admin/users                # Список пользователей
POST   /api/admin/users                # Создать пользователя
PUT    /api/admin/users/{id}           # Обновить пользователя
DELETE /api/admin/users/{id}           # Удалить пользователя
PUT    /api/admin/users/{id}/role      # Изменить роль
PUT    /api/admin/users/{id}/toggle-active  # Блок/разблок
PUT    /api/admin/users/{id}/reset-password # Сменить пароль
POST   /api/admin/users/bulk-reset-passwords # Массовая смена паролей
POST   /api/admin/users/{id}/generate-temporary-password # Генерация временного пароля
GET    /api/admin/stats                # Статистика пользователей
```

## 8. 🔐 Требования к безопасности

### Аутентификация
- ✅ Хеширование паролей (bcrypt)
- ✅ API токены с ограниченным сроком действия
- ✅ Rate limiting (5 попыток входа в минуту)
- ✅ Fail2Ban для защиты от брутфорса

### Авторизация
- ✅ Middleware для проверки ролей
- ✅ Проверка прав доступа в контроллерах
- ✅ Защита от IDOR (неправильный ID)

### Защита данных
- ✅ Валидация всех входных данных
- ✅ Защита от SQL инъекций (prepared statements)
- ✅ Защита от XSS (экранирование)
- ✅ Защита от CSRF

### Сетевая безопасность
- ✅ SSL/TLS сертификаты (Let's Encrypt)
- ✅ CORS настройки
- ✅ Security headers (X-Frame-Options, CSP, HSTS)
- ✅ Firewall (только порты 22, 80, 443)

### База данных
- ✅ Сильные пароли
- ✅ БД недоступна из интернета
- ✅ Регулярные backups
- ✅ Шифрование чувствительных данных
