# 🚀 АВТОЗАПУСК СЕРВЕРА - КРАТКАЯ ИНСТРУКЦИЯ

## ⚡ Настройка за 2 минуты

### Шаг 1: Запустите скрипт настройки

1. Найдите файл **`setup-autostart.bat`** в папке проекта
2. **Правый клик** → **"Запуск от имени администратора"**
3. Дождитесь сообщения об успехе
4. Нажмите любую клавишу

**Готово! ✅**

Теперь сервер будет запускаться автоматически при каждом входе в Windows.

---

## 📁 Файлы для управления

### 🟢 Запуск сервера

| Файл | Описание |
|------|----------|
| **start-server.bat** | Запуск с окном консоли (видно логи) |
| **start-server-silent.vbs** | Запуск в скрытом режиме (без окна) |

### 🔴 Остановка сервера

| Файл | Описание |
|------|----------|
| **stop-server.bat** | Остановка всех процессов сервера |

### 🔧 Управление автозапуском

| Файл | Описание |
|------|----------|
| **setup-autostart.bat** | Настроить автозапуск |
| **remove-autostart.bat** | Удалить автозапуск |

---

## 🎯 Как это работает

### При включении компьютера:

1. Windows загружается
2. Вы входите в систему
3. Автоматически запускается сервер (в скрытом режиме)
4. Сайт доступен: **http://localhost:3000**

### Проверка что сервер работает:

Откройте браузер: **http://localhost:3000**

---

## 🛑 Как остановить сервер

### Способ 1: Через скрипт
```
stop-server.bat
```

### Способ 2: Через диспетчер задач
1. **Ctrl + Shift + Esc**
2. Найдите **node.exe**
3. Правый клик → **Снять задачу**

---

## 🗑️ Как удалить автозапуск

### Способ 1: Через скрипт
```
remove-autostart.bat (от имени администратора)
```

### Способ 2: Вручную
1. **Win + R** → `shell:startup` → **Enter**
2. Удалите файл **"ВКС Расписание.lnk"**

---

## 🔥 Решение проблем

### Сервер не запускается автоматически

**Проверьте:**
1. Файл **start-server-silent.vbs** существует в **D:\BCS**
2. Ярлык создан в папке автозагрузки:
   - **Win + R** → `shell:startup` → **Enter**
   - Должен быть файл **"ВКС Расписание.lnk"**
3. Перезагрузите компьютер

### Порт 3000 занят

```cmd
netstat -ano | findstr :3000
taskkill /PID [номер] /F
start-server.bat
```
