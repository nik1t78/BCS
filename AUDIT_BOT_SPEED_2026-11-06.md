# Оптимизация скорости создания ВКС — 06.11.2026

## Что изменено

1. `vks-bot/bot_pw.py`: Chromium теперь запускается лениво один раз и переиспользуется между запросами. Для каждой конференции создаётся отдельный BrowserContext, который закрывается после результата; это изолирует cookies и состояние встреч.
2. Playwright Sync API выполняется в одном выделенном потоке `ThreadPoolExecutor(max_workers=1)`. Это важно: Playwright Sync нельзя безопасно переносить между потоками, поэтому постоянный браузер не будет случайно использоваться разными FastAPI worker threads.
3. Навигация ждёт `domcontentloaded`, а не полную загрузку `load`; удалена фиксированная пауза 1,5 секунды. Форма ожидается по DOM-селекторам.
4. Для создания комнаты блокируются только изображения, шрифты и медиа. Скрипты, CSS, XHR/fetch и API платформы остаются доступны.
5. Ожидание ссылки переведено на `wait_for_function` с опросом 250 мс. Больше не скачивается полный HTML (`page.content()`) каждую секунду.
6. Добавлено корректное закрытие постоянного Chromium при завершении FastAPI.
7. В Docker queue worker уменьшена пауза ожидания с 3 до 1 секунды, чтобы задача после постановки в очередь начиналась быстрее.
8. Таймаут навигации по умолчанию уменьшен до 45 секунд, число попыток — до 2; если сеть медленная, значения можно переопределить переменными окружения.

## Что сохранено

- SaluteJazz и текущий способ создания комнаты.
- Название встречи, имя организатора и передача даты.
- Существующие API `/create`, `/create-link`, `/check-and-create`.
- Последовательная обработка создания, чтобы не было одновременных кликов/дубликатов в одной сессии.
- Текущая Laravel-очередь, логирование и обработка ошибок.

## Установка

Из папки проекта в PowerShell:

```powershell
docker compose --profile bot up -d --build vks-bot
docker compose up -d --build queue backend scheduler
docker compose exec backend php artisan optimize:clear
docker compose logs --tail=100 vks-bot queue
```

Проверьте, что в `.env` установлено `VKSBOT_EXPECTED=true`, профиль `bot` запущен, а `BOT_TOKENS` совпадает в frontend/backend и vks-bot. Не публикуйте токены в чат.

После установки первый запуск может быть дольше (старт Chromium); следующие запросы должны использовать прогретый процесс браузера. Если SaluteJazz изменит страницу/защитные механизмы, селекторы могут потребовать обновления.
