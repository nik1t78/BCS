# 🔐 Система безопасности и управление паролями

## 📋 Обзор

Пароли администратора и модератора **НЕ хранятся в коде** - они создаются только в базе данных при первом запуске системы.

---

## 🚀 Первый запуск системы

### 1. Автоматическое создание администратора

При первом запуске приложения автоматически создаётся **один администратор** с временным паролем:

- **Логин:** `admin`
- **Пароль:** Генерируется автоматически (например: `tempa7f9k2m3`)
- **Роль:** `admin`
- **Статус:** Требует смены пароля

### 2. Где посмотреть временный пароль

Временный пароль отображается на странице входа в жёлтом блоке:

```
┌─────────────────────────────────────┐
│ 🔑 Первый вход в систему           │
├─────────────────────────────────────┤
│ Временный пароль администратора:   │
│                                     │
│ Логин: admin                       │
│ Пароль: tempa7f9k2m3               │
│                                     │
│ ℹ️ После входа необходимо          │
│    сменить пароль                   │
└─────────────────────────────────────┘
```

### 3. Первый вход и смена пароля

1. Откройте приложение: **http://localhost:5173**
2. Введите логин: `admin`
3. Введите временный пароль (показан на странице входа)
4. Нажмите **"Войти"**
5. Система автоматически перенаправит на страницу смены пароля
6. Введите новый пароль (минимум 6 символов)
7. Подтвердите пароль
8. Нажмите **"Сохранить пароль"**

После этого временный пароль удаляется и больше не отображается.

## 👥 Создание дополнительных пользователей

### Через админ-панель

1. Войдите как администратор
2. Перейдите в **"Админ-панель"**
3. Выберите вкладку **"Пользователи"**
4. Нажмите **"Добавить пользователя"**
5. Заполните форму:
   - ФИО
   - Логин
   - Пароль (придумайте сами)
   - Роль (admin/moderator/user)
   - Телефон (опционально)
   - Отдел (опционально)
6. Нажмите **"Создать"**

### Через регистрацию

Любой пользователь может зарегистрироваться самостоятельно:

1. На странице входа нажмите вкладку **"Регистрация"**
2. Заполните форму:
   - ФИО
   - Логин
   - Пароль (минимум 6 символов)
   - Телефон (опционально)
   - Отдел (опционально)
3. Нажмите **"Зарегистрироваться"**
4. Новый пользователь автоматически получает роль `user`

## 🔑 Смена пароля

### Пользователь может сменить свой пароль:

1. Перейдите в **"Профиль"**
2. Найдите раздел **"Безопасность"**
3. Нажмите **"Сменить пароль"**
4. Введите текущий пароль
5. Введите новый пароль
6. Подтвердите новый пароль
7. Нажмите **"Сохранить"**

### Администратор может сменить пароль любому пользователю:

1. Перейдите в **"Админ-панель"** → **"Пользователи"**
2. Найдите нужного пользователя
3. Нажмите на иконку **🔑** (ключ)
4. Введите новый пароль
5. Подтвердите пароль
6. Нажмите **"Изменить пароль"**

- ✅ Смена паролей всех пользователей

- ✅ Публичные конференции
- ✅ Профиль и настройки
- ✅ Создание конференций
- ✅ Смена своего пароля

- ❌ Приватные конференции (если не участник)

## 🔍 Проверка безопасности

### Как проверить что пароли не в коде:

```bash
# Поиск захардкоженных паролей
grep -r "admin123" src/
grep -r "mod123" src/
grep -r "user123" src/

# Результат должен быть пустым
```

### Как проверить временный пароль:

```javascript
// В консоли браузера
localStorage.getItem('vks_admin_temp_password');
// Вернёт временный пароль или null если уже сменён
```

### Как проверить флаг смены пароля:

```javascript
// В консоли браузера
const users = JSON.parse(localStorage.getItem('vks_users'));
users.forEach(u => {
  console.log(`${u.login}: mustChangePassword = ${u.mustChangePassword}`);
});
```
