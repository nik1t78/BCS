# ✅ ПРОВЕРКА РАБОТЫ API

## 🎯 Что изменилось

Frontend теперь работает с **API Laravel** вместо localStorage. Это значит:

✅ **Все пользователи видят общие данные** из базы MySQL  
✅ **Конференции синхронизируются** в реальном времени  
✅ **Уведомления работают** для всех пользователей  
✅ **Данные сохраняются** на сервере, а не в браузере  

---

## 🔍 Проверка работы API

### Шаг 1: Убедитесь что MySQL запущен

```powershell
docker compose ps mysql
```

Должен быть статус **Up**.

### Шаг 2: Проверьте что backend работает

```powershell
docker compose ps backend
```

Должен быть статус **Up**.

### Шаг 3: Проверьте API health check

```powershell
curl http://localhost/api/health
```

Должны получить ответ:
```json
{"status":"ok","timestamp":"2026-09-21T11:00:00+00:00","version":"1.0.0"}
```

### Шаг 4: Проверьте получение пользователей

```powershell
curl http://localhost/api/users
```

Должны получить список пользователей в формате JSON.

### Шаг 5: Проверьте получение конференций

```powershell
curl http://localhost/api/meetings
```

Должны получить список конференций в формате JSON.


## ✅ Проверка многопользовательской работы

### Тест 1: Создание конференции

1. Войдите как `admin` / `admin123`
2. Перейдите в "Мои конференции"
3. Нажмите "Создать конференцию"
4. Заполните форму:
   - Название: "Тестовая конференция"
   - Дата: сегодня
   - Время: через 1 час
   - Выберите участников
5. Нажмите "Создать"

### Тест 2: Проверка видимости

1. Откройте **второй браузер** (или режим инкогнито)
2. Войдите как `ivanov` / `user123`
3. Перейдите в "Расписание"
4. ✅ **Должны видеть созданную конференцию**

### Тест 3: Проверка уведомлений

1. Во втором браузере (как ivanov) перейдите в "Уведомления"
2. ✅ **Должно быть уведомление** о добавлении в конференцию

### Тест 4: Проверка синхронизации

1. В первом браузере (как admin) удалите конференцию
2. Во втором браузере (как ivanov) обновите страницу
3. ✅ **Конференция должна исчезнуть**

## 🐛 Решение проблем

### Проблема: API не отвечает

```powershell
# Проверьте что backend запущен
docker compose ps backend

# Перезапустите backend
docker compose restart backend

# Проверьте логи
docker compose logs backend --tail=50
```

### Проблема: Ошибки CORS

```powershell
# Проверьте конфигурацию CORS
docker compose exec backend cat config/cors.php

# Очистите кэш
docker compose exec backend php artisan config:clear

# Перезапустите backend
docker compose restart backend
```

### Проблема: Данные не синхронизируются

```powershell
# Проверьте что frontend использует API
# Откройте DevTools (F12) → Network
# Должны видеть запросы к /api/*

# Проверьте что backend возвращает данные
curl http://localhost/api/meetings
```
