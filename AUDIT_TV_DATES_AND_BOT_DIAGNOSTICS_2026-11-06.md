# Изменения: даты на ТВ, страница всех ВКС и диагностика бота

## Экран ТВ
- В списке ближайших ВКС теперь выводится календарная дата отдельной строкой под названием.
- Добавлена ссылка «Все ВКС этого зала».
- Добавлена отдельная публичная страница `/tv/{room}/all?token=...` с расписанием на ближайшие 30 дней.
- Данные страницы защищены тем же токеном помещения; выдаются только нейтральные поля: название, дата, время, статус и ссылка входа.
- Добавлен API `/api/tv/{room}/all`, включая occurrence'ы повторяющихся встреч.
- Страница автоматически обновляет список каждые 30 секунд.

## Бот SaluteJazz
- Удалён безусловный `wait_for_selector`, который выбрасывал TimeoutError через 20 секунд и прерывал более гибкий механизм ожидания SPA, находившийся ниже в коде.
- При отсутствии формы теперь в лог записываются URL, заголовок страницы и короткий текст body; сохраняется полноразмерный скриншот `/tmp/vksbot_fail.png`.
- При ошибке больше не генерируется случайная `fallback_link`: такая ссылка не является реально созданной комнатой и могла вводить пользователей в заблуждение.

## Проверки
- `php -l` для изменённых PHP-файлов: успешно.
- `python -m py_compile` для `vks-bot/bot_pw.py` и `vks-bot/server.py`: успешно.
- Интеграционный запуск с реальным SaluteJazz, MySQL и браузером пользователя в этой среде не выполнялся.

## Диагностика на сервере при повторной ошибке бота
```powershell
docker compose logs --tail=150 vks-bot
docker compose cp vks-bot:/tmp/vksbot_fail.png .\vksbot_fail.png
```
Скриншот поможет определить, что видит бот: форму, страницу авторизации, капчу, ошибку сайта или изменившийся интерфейс.
