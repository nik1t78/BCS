# 🚨 Не вижу изменений в предварительном просмотре

## ⚠️ Проблема

Вы не видите новые функции в предварительном просмотре:
- ❌ Не отображается блок "Кабинет"
- ❌ Не видна кнопка "Подключиться к конференции"
- ❌ Не отображается место проведения с подписью

## ✅ Решение

### Используйте кнопку "Сброс данных"

В правом нижнем углу экрана появилась **красная кнопка с иконкой корзины** 🗑️

**Шаги:**

1. **Найдите кнопку** в правом нижнем углу
   - Красная кнопка с текстом "Сброс данных"
   - Иконка корзины 🗑️

2. **Нажмите на кнопку**
   - Появится окно подтверждения

3. **Подтвердите сброс**
   - Нажмите "Сбросить"
   - Дождитесь перезагрузки страницы

4. **Войдите снова**
   - Используйте демо-аккаунты:
     - Админ: `admin@vks.local` / `admin123`
     - Модератор: `sidorov@vks.local` / `mod123`
     - Пользователь: `ivanov@vks.local` / `user123`

5. **Проверьте изменения**
   - Теперь все новые функции должны быть видны!

## 🔍 Почему это происходит?

Когда вы впервые открываете приложение, загружаются демо-данные и сохраняются в localStorage браузера. Если вы уже открывали приложение до добавления новых функций, старые данные не содержат новых полей.

**Сброс данных удаляет старые данные и загружает новые демо-данные с актуальными полями.**

## 💡 Альтернативные способы

### Способ 1: Через консоль браузера

```javascript
// Откройте консоль (F12) и введите:
localStorage.clear()
// Обновите страницу (F5)
```

### Способ 2: Через DevTools

1. Нажмите `F12`
2. Вкладка **Application** → **Local Storage**
3. Нажмите **Clear all**
4. Обновите страницу

### Способ 3: Приватный режим

Откройте браузер в режиме инкогнито и войдите заново.

## ✅ Чек-лист

После сброса данных проверьте:

- [ ] Кнопка "Сброс данных" видна в правом нижнем углу
- [ ] Блок "Следующая конференция" отображается полностью
- [ ] Блок "Кабинет" виден в дополнительной информации
- [ ] Кнопка "Подключиться к конференции" всегда видна
- [ ] Место проведения отображается с подписью
- [ ] Список конференций на сегодня содержит информацию о кабинетах
