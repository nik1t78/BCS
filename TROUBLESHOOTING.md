# 🔧 Решение проблемы: не видно изменений

## 📋 Проблема

Если вы не видите изменения в предварительном просмотре, возможно:
1. Старые данные в localStorage не содержат новые поля
2. Кэш браузера
3. Демо-данные были загружены до добавления новых функций

## ✅ Решение

### Способ 1: Очистить localStorage через консоль браузера

1. Откройте приложение в браузере
2. Нажмите `F12` (откроется консоль разработчика)
3. Перейдите на вкладку **Console**
4. Введите команду:

```javascript
localStorage.clear()
```

5. Обновите страницу (`F5` или `Ctrl+R`)
6. Войдите снова (демо-данные загрузятся заново)

### Способ 2: Очистить через DevTools

1. Откройте приложение в браузере
2. Нажмите `F12`
3. Перейдите на вкладку **Application** (или **Storage**)
4. В左侧菜单 выберите **Local Storage** → **ваш домен**
5. Нажмите **Clear all** (очистить всё)
6. Обновите страницу

### Способ 3: Использовать приватный режим

1. Откройте браузер в режиме инкогнито/приватности
2. Перейдите по ссылке на приложение
3. Войдите в систему (демо-данные загрузятся с новыми полями)

## 🔍 Проверка данных

Чтобы убедиться, что данные загружены правильно:

1. Откройте консоль браузера (`F12`)
2. Введите команду:

```javascript
JSON.parse(localStorage.getItem('vks_meetings'))
```

3. Проверьте, что у каждой конференции есть поле `room`:

```javascript
{
  id: "...",
  title: "Обзор проекта Q4",
  room: "Конференц-зал А",  // ← Это поле должно быть!
  // ... другие поля
}
```

## 💡 Если проблема не решена

### Проверьте версию приложения

1. Откройте консоль браузера (`F12`)
2. Введите:

```javascript
// Проверить версию
console.log('Версия приложения: 1.0')

// Проверить наличие функций
console.log('Тёмная тема:', typeof localStorage.getItem('vks_theme'))
console.log('Шаблоны:', typeof localStorage.getItem('vks_templates'))
console.log('Теги:', typeof localStorage.getItem('vks_tags'))
```

