# ✅ Исправлено: Кнопка подключения к конференции

## 📋 Проблема

В блоке "Следующая конференция" кнопка "Подключиться к ВКС" отображалась **только если** у конференции была указана ссылка. Если ссылки не было, кнопка не отображалась вообще.

## 🔧 Что было исправлено

Теперь кнопка **"Подключиться к конференции"** отображается **ВСЕГДА** в блоке "Следующая конференция":

### Если ссылка есть:
```
[🎥 Подключиться к конференции]  ← Синяя активная кнопка
```

### Если ссылки нет:
```
[🎥 Ссылка не указана]  ← Серая неактивная кнопка
```

## 🔍 Как это работает

### Логика отображения:

```typescript
<button
  onClick={() => setJoiningMeeting(nextMeeting)}
  className={`... ${
    nextMeeting.link 
      ? 'bg-blue-600 text-white hover:bg-blue-700'  // Активная
      : 'bg-gray-400 text-gray-100 cursor-not-allowed'  // Неактивная
  }`}>
  <i className="fas fa-video"></i>
  {nextMeeting.link ? 'Подключиться к конференции' : 'Ссылка не указана'}
</button>
```

### Поведение:

1. **Если есть ссылка** (`nextMeeting.link` существует):
   - Кнопка синяя (`bg-blue-600`)
   - Текст: "Подключиться к конференции"
   - При нажатии открывается модальное окно подключения

2. **Если нет ссылки** (`nextMeeting.link` отсутствует):
   - Кнопка серая (`bg-gray-400`)
   - Текст: "Ссылка не указана"
   - При нажатии открывается модальное окно с предупреждением
