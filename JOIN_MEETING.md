# 🎥 Подключение к конференции

## 📋 Описание

Система подключения к видеоконференциям позволяет пользователям быстро и удобно присоединяться к встречам через модальное окно с подробной информацией и инструкциями.

---

## 🚀 Как это работает

### 1. Кнопка "Подключиться"

Когда у конференции есть ссылка на ВКС, отображается кнопка **"Подключиться"** (вместо простой ссылки).

**Где отображается:**
- ✅ Главная страница (Dashboard) - следующая конференция
- ✅ Расписание (Schedule) - список конференций на день
- ✅ Мои конференции (UserPanel) - список всех конференций

### 2. Модальное окно подключения

При нажатии на кнопку открывается модальное окно с:

#### 📊 Информация о конференции
- Название конференции
- Описание (если есть)
- Дата и время
- Комната/переговорная
- Платформа (Zoom, Teams, Google Meet и т.д.)

#### 🔗 Способы подключения
- **Большая кнопка** "Подключиться к [платформа]"
- **Ссылка для подключения** с кнопкой копирования
- **Инструкция** по подключению (шаги 1-2-3)

#### 💡 Советы для платформы
Автоматические советы для конкретной платформы:
- **Zoom**: установка клиента, проверка микрофона, виртуальный фон
- **Microsoft Teams**: вход в аккаунт, разрешения, фоновые эффекты
- **Google Meet**: использование Chrome, доступ к камере, шумоподавление

#### 👥 Участники
Список всех зарегистрированных участников конференции

## 📱 Пошаговая инструкция

### Шаг 1: Нажмите "Подключиться"
Найдите конференцию в списке и нажмите кнопку **"Подключиться"**

### Шаг 2: Изучите информацию
В модальном окне вы увидите:
- Название и описание конференции
- Дату, время и место
- Платформу видеосвязи

### Шаг 3: Выберите способ подключения

#### Вариант А: Кнопка "Подключиться"
1. Нажмите большую цветную кнопку платформы
2. Откроется новая вкладка с конференцией
3. Следуйте инструкциям платформы

#### Вариант Б: Копирование ссылки
1. Скопируйте ссылку кнопкой **"Копировать"**
2. Откройте приложение платформы
3. Вставьте ссылку в поле "Присоединиться"

### Шаг 4: Настройте оборудование
- Разрешите доступ к камере
- Разрешите доступ к микрофону
- Проверьте настройки звука и видео

### Шаг 5: Подключитесь
- Введите имя участника (если требуется)
- Дождитесь подключения
- Проверьте, что вас слышно и видно

## 🔧 Технические детали

### Компонент
- **Файл**: `src/components/JoinMeetingModal.tsx`
- **Тип**: Модальное окно
- **Состояние**: `joiningMeeting` в родительских компонентах

### Интеграция
Компонент интегрирован в:
- `Dashboard.tsx` - главная страница
- `Schedule.tsx` - расписание
- `UserPanel.tsx` - мои конференции

### Функции
```typescript
// Определение платформы по ссылке
detectPlatform(link: string): { name: string; icon: string; color: string }

// Копирование ссылки
copyLink(): void

// Подключение к конференции
joinMeeting(): void
```

### Состояния
- `copied` - статус копирования ссылки (показывает "Скопировано")
- `joiningMeeting` - текущая конференция для подключения

## 📋 Примеры использования

### Пример 1: Подключение к Zoom
1. Найдите конференцию в списке
2. Нажмите **"Подключиться"**
3. В модальном окне увидите "Zoom" с синей иконкой
4. Нажмите **"Подключиться к Zoom"**
5. Откроется Zoom приложение или веб-версия
6. Введите имя и подключитесь

### Пример 2: Подключение к Teams
1. Найдите конференцию
2. Нажмите **"Подключиться"**

4. Нажмите **"Подключиться к Microsoft Teams"**
5. Войдите в Microsoft аккаунт
6. Присоединитесь к встрече

### Пример 3: Копирование ссылки
1. Откройте модальное окно
2. Найдите поле "Ссылка для подключения"
3. Нажмите **"Копировать"**
4. Откройте приложение платформы
5. Вставьте ссылку в поле "Присоединиться"

## 🔐 Безопасность

### Что проверяется:
- ✅ Ссылка должна быть валидным URL
- ✅ Платформа определяется автоматически
- ✅ Ссылка открывается в новой вкладке
- ✅ Копирование через Clipboard API

### Рекомендации:
- 🔒 Проверяйте ссылку перед подключением
- 🔒 Используйте только официальные приложения
- 🔒 Не передавайте ссылку посторонним
- 🔒 Используйте сложные пароли для встреч

## 🐛 Решение проблем

### Проблема: Кнопка не работает
**Решение**: Проверьте, что у конференции есть ссылка в поле `link`

### Проблема: Ссылка не копируется
**Решение**: Проверьте разрешения браузера на использование Clipboard API

### Проблема: Платформа не определяется
**Решение**: Ссылка откроется как "Видеоконференция" с серой иконкой

### Проблема: Модальное окно не закрывается
**Решение**: Нажмите на крестик [X] или кнопку "Закрыть"
