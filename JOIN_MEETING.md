# 🎥 Подключение к конференции

## 📋 Как это работает

Система подключения к конференциям работает очень просто:

1. **Пользователь создаёт конференцию** и указывает ссылку на видеоконференцию (Zoom, Teams, Google Meet и т.д.)
2. **Другие пользователи видят кнопку "Подключиться"** в списке конференций
3. **При нажатии на кнопку** открывается модальное окно с информацией о конференции
4. **При нажатии "Открыть ссылку"** открывается именно та ссылка, которую предоставил пользователь

---

## 🔄 Процесс подключения

### Шаг 1: Создание конференции

Когда вы создаёте конференцию, вы указываете:
- Название
- Дату и время
- **Ссылку на видеоконференцию** (это может быть Zoom, Teams, Google Meet или любая другая платформа)
- Комнату (если есть физическая переговорная)
- Описание и участников

**Пример ссылки:**
```
https://zoom.us/j/123456789?pwd=abc123
https://teams.microsoft.com/l/meetup-join/...
https://meet.google.com/abc-defg-hij
```

### Шаг 2: Просмотр конференций

Другие пользователи видят вашу конференцию в списках:
- На главной странице (Dashboard)
- В расписании (Schedule)
- В "Мои конференции" (UserPanel)

Рядом с конференцией отображается кнопка **"Подключиться"** (если указана ссылка).

### Шаг 3: Модальное окно подключения

При нажатии на кнопку "Подключиться" открывается модальное окно, в котором отображается:

#### 📊 Информация о конференции
- Название конференции
- Описание
- Дата и время
- Комната/переговорная

#### 🔗 Способы подключения

**Вариант 1: Кнопка "Открыть ссылку на конференцию"**
- Большая синяя кнопка
- При нажатии открывается новая вкладка с ссылкой, которую вы указали
- Пользователь попадает прямо на конференцию

**Вариант 2: Копирование ссылки**
- Поле с ссылкой для подключения
- Кнопка "Копировать"
- Пользователь может скопировать ссылку и вставить её в приложение видеоконференции

#### 📝 Инструкция
Пошаговая инструкция:
1. Нажмите кнопку "Открыть ссылку на конференцию"
2. Откроется новая вкладка с конференцией
3. Разрешите доступ к камере и микрофону
4. Дождитесь подключения
5. Введите имя участника (если требуется)

#### 💡 Полезные советы
- Убедитесь в стабильном интернет-соединении
- Проверьте настройки микрофона и камеры
- Используйте наушники для лучшего звука
- Выберите тихое место

#### 👥 Список участников
Отображается список всех зарегистрированных участников конференции

## 💻 Техническая реализация

### Что происходит при нажатии "Подключиться"

```typescript
const joinMeeting = () => {
  if (meeting.link) {
    // Открываем ссылку, которую предоставил пользователь
    window.open(meeting.link, '_blank', 'noopener,noreferrer');
  }
};
```

**Важно:**
- Система **НЕ создаёт** ссылки на конференции
- Система **НЕ определяет** платформу автоматически
- Система **просто открывает** ту ссылку, которую указал пользователь при создании конференции

### Пример

**Пользователь создаёт конференцию:**
```javascript
{
  title: "Еженедельный стендап",
  date: "2024-01-15",
  startTime: "10:00",
  endTime: "10:30",
  link: "https://zoom.us/j/123456789?pwd=abc123", // ← Ссылка от пользователя
  room: "Переговорная №1",
  participants: [...]
}
```

**Другой пользователь нажимает "Подключиться":**
1. Открывается модальное окно
2. Видит информацию о конференции
3. Нажимает "Открыть ссылку на конференцию"
4. Открывается `https://zoom.us/j/123456789?pwd=abc123` в новой вкладке
5. Пользователь попадает на Zoom конференцию

## 📱 Пошаговая инструкция для пользователей

### Для организатора (создание конференции)

1. Откройте "Мои конференции"
2. Нажмите "Создать конференцию"
3. Заполните форму:
   - **Название**: "Еженедельный стендап"
   - **Дата**: выберите дату
   - **Время начала**: 10:00
   - **Время окончания**: 10:30
   - **Ссылка на ВКС**: вставьте ссылку из Zoom/Teams/Google Meet
   - **Комната**: "Переговорная №1" (если есть)
   - **Описание**: "Обсуждение прогресса команды"
   - **Участники**: выберите участников из списка
4. Нажмите "Создать"

### Для участника (подключение к конференции)

1. Откройте главную страницу или "Мои конференции"
2. Найдите нужную конференцию
3. Нажмите кнопку **"Подключиться"**
4. В модальном окне проверьте информацию:
   - Название конференции
   - Дата и время
   - Комната
5. Нажмите **"Открыть ссылку на конференцию"**
6. Откроется новая вкладка с конференцией
7. Разрешите доступ к камере и микрофону
8. Дождитесь подключения

## 🚨 Если нет ссылки

Если организатор не указал ссылку на конференцию:

1. Кнопка "Подключиться" **не отображается**
2. В модальном окне (если открыть другим способом) показывается предупреждение:
   ```
   ⚠️ Ссылка на конференцию не указана
   
   Обратитесь к организатору для получения ссылки на подключение
   ```

**Решение:**
- Свяжитесь с организатором
- Попросите прислать ссылку на конференцию
- Организатор может отредактировать конференцию и добавить ссылку

## 🔐 Безопасность

### Что проверяется:
- ✅ Ссылка должна быть валидным URL
- ✅ Ссылка открывается в новой вкладке
- ✅ Используются атрибуты `noopener,noreferrer` для безопасности
- ✅ Копирование через Clipboard API

### Рекомендации:
- 🔒 Проверяйте ссылку перед подключением
- 🔒 Убеждайтесь, что ссылка от доверенного источника
- 🔒 Не передавайте ссылку посторонним
- 🔒 Используйте сложные пароли для встреч (если платформа поддерживает)

## 🛠️ Для разработчиков

### Компонент

**Файл:** `src/components/JoinMeetingModal.tsx`

**Props:**
```typescript
interface JoinMeetingModalProps {
  meeting: Meeting;  // Объект конференции
  onClose: () => void;  // Функция закрытия модального окна
}
```

**Основные функции:**

```typescript
// Открыть ссылку пользователя
const joinMeeting = () => {
  if (meeting.link) {
    window.open(meeting.link, '_blank', 'noopener,noreferrer');
  }
};

// Скопировать ссылку
const copyLink = () => {
  if (meeting.link) {
    navigator.clipboard.writeText(meeting.link);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  }
};
```

### Интеграция

Компонент интегрирован в:
- `Dashboard.tsx` - кнопка "Подключиться" у следующей конференции
- `Schedule.tsx` - кнопка "Подключиться" в списке конференций
- `UserPanel.tsx` - кнопка "Подключиться" в "Мои конференции"

**Пример использования:**
```typescript
const [joiningMeeting, setJoiningMeeting] = useState<Meeting | null>(null);

// Кнопка
<button onClick={() => setJoiningMeeting(meeting)}>
  Подключиться
</button>

// Модальное окно
{joiningMeeting && (
  <JoinMeetingModal
    meeting={joiningMeeting}
    onClose={() => setJoiningMeeting(null)}
  />
)}
```
