# ⚡ БЫСТРЫЙ СТАРТ: ЗАПУСК ПРОЕКТА ЛОКАЛЬНО

## 🎯 За 5 минут

### 1. Откройте командную строку

Нажмите **Win + R**, введите `cmd`, нажмите **Enter**

### 2. Перейдите в папку проекта

```cmd
cd D:\BCS
```

### 3. Установите зависимости (если ещё не установлены)

```cmd
npm install
```

Ждите 2-5 минут...

### 4. Соберите проект

```cmd
npm run build
```

Ждите 10-30 секунд...

### 5. Установите веб-сервер (один раз)

```cmd
npm install -g serve
```

### 6. Запустите сервер

```cmd
serve -s dist -l 3000
```

### 7. Откройте браузер

Перейдите по адресу: **http://localhost:3000**

### 8. Войдите в систему

- **Логин:** `admin`
- **Пароль:** `admin123`

**Готово! 🎉**

## 🌍 Чтобы другие могли подключиться

### 1. Узнайте IP адрес

В **НОВОМ** окне командной строки:

```cmd
ipconfig
```

Запомните **IPv4-адрес** (например: `192.168.1.100`)

### 2. Откройте порт в firewall

Запустите командную строку **ОТ ИМЕНИ АДМИНИСТРАТОРА**:

```cmd
netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
```

### 3. Готово!

Теперь другие могут открыть: **http://192.168.1.100:3000**

## 🆘 Если что-то не работает

### Порт занят

```cmd
netstat -ano | findstr :3000
taskkill /PID [номер] /F
serve -s dist -l 3000
```

### Очистка данных

В браузере нажмите **F12** → Console → введите:

```javascript
localStorage.clear()
```

Обновите страницу (**F5**)
