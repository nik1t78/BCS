## 📥 ШАГ 1: Установка Node.js

### 1.1. Скачайте Node.js

1. Откройте браузер
2. Перейдите на сайт: **https://nodejs.org/**
3. Нажмите на большую зелёную кнопку **"LTS"** (рекомендуемая версия)
4. Дождитесь скачивания файла `node-v20.x.x-x64.msi`

### 1.2. Установите Node.js

1. Найдите скачанный файл
2. **Дважды кликните** по нему
3. Нажмите **"Next"** (Далее)
4. Примите лицензионное соглашение: поставьте галочку **"I accept the terms in the License Agreement"**
5. Нажмите **"Next"**
6. Оставьте путь по умолчанию: `C:\Program Files\nodejs\`
7. Нажмите **"Next"**
8. Оставьте все компоненты по умолчанию
9. Нажмите **"Next"**
10. Нажмите **"Install"** (Установить)
11. Дождитесь окончания установки
12. Нажмите **"Finish"** (Завершить)

### 1.3. Проверьте установку

1. Нажмите **Win + R** (откроется окно "Выполнить")
2. Введите `cmd` и нажмите **Enter**
3. В открывшемся чёрном окне введите команду:

```cmd
node --version
```

4. Нажмите **Enter**
5. Должно появиться что-то вроде: `v20.11.0`

6. Введите вторую команду:

```cmd
npm --version
```

7. Нажмите **Enter**
8. Должно появиться что-то вроде: `10.2.4`

**Если видите версии - всё установлено правильно! ✅**

## 🔧 ШАГ 4: Установка зависимостей

### 4.1. Откройте папку проекта в командной строке

1. Откройте командную строку (Win + R → cmd → Enter)

2. Перейдите в папку проекта:

```cmd
cd D:\BCS
```

(или в вашу папку с проектом)

### 4.2. Установите все необходимые библиотеки

В командной строке введите:

```cmd
npm install
```

Нажмите **Enter**

**Что произойдёт:**
- Начнётся скачивание всех необходимых библиотек
- Это займёт **2-5 минут** в зависимости от скорости интернета
- В командной строке будет отображаться прогресс
- В конце должно появиться что-то вроде: `added 250 packages in 2m`

**Не закрывайте окно!** Дождитесь окончания установки.

### 4.3. Проверьте что всё установилось

После окончания установки в папке проекта должна появиться папка `node_modules`.

Проверьте:

```cmd
dir node_modules
```

Должен показать список файлов и папок.

**Если папка `node_modules` есть - всё установилось правильно! ✅**

## 🏗️ ШАГ 5: Сборка проекта

### 5.1. Соберите проект для production

В командной строке (в папке проекта) введите:

```cmd

```

Нажмите **Enter**

**Что произойдёт:**

- Это займёт **10-30 секунд**

Проверьте что папка `dist` создана:


## 🌐 ШАГ 6: Запуск локального сервера

### 6.1. Установите простой веб-сервер

В командной строке введите:

```cmd
npm install -g serve
```

Нажмите **Enter**

Дождитесь окончания установки (30 секунд - 1 минута).

### 6.2. Запустите сервер

В командной строке введите:

```cmd
serve -s dist -l 3000
```

Нажмите **Enter**

**Что произойдёт:**
- Запустится локальный веб-сервер
- В командной строке появится сообщение:

```
   ┌────────────────────────────────────────────────────┐
   │                                                    │
   │   Serving!                                         │
   │                                                    │
   │   - Local:    http://localhost:3000                │
   │   - Network:  http://192.168.1.100:3000            │
   │                                                    │
   └────────────────────────────────────────────────────┘
```

**НЕ ЗАКРЫВАЙТЕ ЭТО ОКНО!** Сервер работает пока окно открыто.

### 6.3. Откройте сайт в браузере

1. Откройте браузер (Chrome, Firefox, Edge)
2. В адресной строке введите:

```
http://localhost:3000
```

3. Нажмите **Enter**

**Должна открыться страница входа в систему! 🎉**

## 🔓 ШАГ 7: Первый вход в систему

### 7.1. Войдите как администратор

На странице входа введите:

- **Логин:** `admin`
- **Пароль:** `admin123`

Нажмите **"Войти"**

**Если вход не работает:**

1. Нажмите **F12** (откроется консоль разработчика)
2. Перейдите на вкладку **Console**
3. Вставьте эту команду:

```javascript
localStorage.clear()
```

4. Нажмите **Enter**
5. Обновите страницу (**F5**)
6. Попробуйте войти снова

### 7.2. Назначьте себе роль администратора

После входа:

1. Нажмите **F12** (консоль разработчика)
2. Перейдите на вкладку **Console**
3. Вставьте эту команду:

```javascript
const users = JSON.parse(localStorage.getItem('vks_users'));
const admin = users.find(u => u.login === 'admin');
admin.role = 'admin';
localStorage.setItem('vks_users', JSON.stringify(users));
location.reload();
```

4. Нажмите **Enter**
5. Страница перезагрузится
6. Теперь вы администратор! ✅

## 🌍 ШАГ 9: Открытие доступа для других компьютеров в сети

### 9.1. Узнайте IP адрес вашего компьютера

1. Откройте **НОВОЕ** окно командной строки (Win + R → cmd → Enter)
2. Введите команду:

```cmd
ipconfig
```

3. Нажмите **Enter**
4. Найдите строку **"IPv4-адрес"**
5. Запомните адрес, например: `192.168.1.100`

### 9.2. Откройте порт в firewall

1. Откройте командную строку **ОТ ИМЕНИ АДМИНИСТРАТОРА**:
   - Нажмите **Пуск**
   - Введите `cmd`
   - **Правый клик** на "Командная строка"
   - Выберите **"Запуск от имени администратора"**

2. Введите команду:

```cmd
netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
```

3. Нажмите **Enter**
4. Должно появиться: **"ОК."**

### 9.3. Проверьте доступ из сети

1. На **ДРУГОМ компьютере** в той же сети откройте браузер
2. Введите адрес:

```
http://192.168.1.100:3000
```

(замените `192.168.1.100` на ваш IP адрес)

3. Нажмите **Enter**

**Должна открыться страница входа! 🎉**

## 🛠️ ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: "Port 3000 is already in use"

**Решение:**

```cmd
:: Найдите процесс который занимает порт
netstat -ano | findstr :3000

:: Убейте процесс (замените PID на номер из предыдущей команды)
taskkill /PID 12345 /F

:: Запустите сервер снова
serve -s dist -l 3000
```

### Проблема 2: "npm install" зависает

**Решение:**

```cmd
:: Очистите кэш npm
npm cache clean --force

:: Удалите папку node_modules
rmdir /s /q node_modules

:: Удалите файл package-lock.json
del package-lock.json

:: Установите заново
npm install
```

### Проблема 3: Сотрудники не могут подключиться

**Решение:**

1. Проверьте что сервер запущен (окно командной строки открыто)
2. Проверьте что firewall открыт:

```cmd
netsh advfirewall firewall show rule name="ВКС Расписание"
```

3. Проверьте IP адрес:

```cmd
ipconfig
```

4. Проверьте доступность порта:

```cmd
Test-NetConnection -ComputerName 192.168.1.100 -Port 3000
```

### Проблема 4: "npm run build" выдаёт ошибку

**Решение:**

```cmd
:: Обновите npm
npm install -g npm@latest

:: Удалите node_modules и package-lock.json
rmdir /s /q node_modules
del package-lock.json

:: Установите заново
npm install

:: Попробуйте собрать снова
npm run build
```

### Проблема 5: Сайт открывается, но не работает

**Решение:**

1. Очистите кэш браузера: **Ctrl + Shift + Delete**
2. Очистите localStorage:
   - Нажмите **F12**
   - Вкладка **Console**
   - Введите: `localStorage.clear()`
   - Нажмите **Enter**
3. Обновите страницу: **F5**
