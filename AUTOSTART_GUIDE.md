# 🚀 АВТОЗАПУСК СЕРВЕРА ВКС РАСПИСАНИЕ

## 📋 Что будет сделано

После настройки сервер будет **автоматически запускаться** при каждом включении компьютера и входе в Windows.

---

## ⚡ БЫСТРАЯ НАСТРОЙКА (2 минуты)

### Шаг 1: Запустите скрипт настройки

1. Найдите файл **`setup-autostart.bat`** в папке проекта
2. **Правый клик** → **"Запуск от имени администратора"**
3. Дождитесь сообщения об успешной настройке
4. Нажмите любую клавишу

**Готово! ✅**

Теперь сервер будет запускаться автоматически при каждом входе в Windows.

## 🔧 АЛЬТЕРНАТИВНЫЕ СПОСОБЫ

### Способ 1: Через скрипт (рекомендуется)

5. Готово!

1. Нажмите **Win + R**
2. Введите: `taskschd.msc`
3. Нажмите **Enter**
4. Справа нажмите **"Создать простую задачу..."**
5. Название: **ВКС Расписание**
6. Триггер: **При входе в систему**
7. Действие: **Запустить программу**
8. Программа: **D:\BCS\start-server-silent.vbs**
9. Нажмите **Готово**

## 🎯 КАК ЭТО РАБОТАЕТ

### При включении компьютера:

1. Windows загружается
2. Вы входите в систему
3. Автоматически запускается **start-server-silent.vbs**
4. Сервер стартует в скрытом режиме (без окна)
5. Сайт доступен по адресу: **http://localhost:3000**

### Проверка что сервер работает:

1. Откройте браузер
2. Перейдите: **http://localhost:3000**
3. Должна открыться страница входа

```cmd

```

## 🔥 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: Сервер не запускается автоматически

**Решение:**

1. Проверьте что файл **start-server-silent.vbs** существует в папке **D:\BCS**
2. Проверьте что ярлык создан в папке автозагрузки:
   - Нажмите **Win + R**
   - Введите: `shell:startup`
   - Должен быть файл **"ВКС Расписание.lnk"**
3. Перезагрузите компьютер

### Проблема: Порт 3000 занят

**Решение:**

```cmd
:: Найдите процесс
netstat -ano | findstr :3000

:: Остановите процесс (замените PID)
taskkill /PID 12345 /F

:: Запустите сервер снова
start-server.bat
```

### Проблема: Сервер запускается, но сайт не открывается

**Решение:**

1. Проверьте firewall:
   ```cmd
   netsh advfirewall firewall show rule name="ВКС Расписание"
   ```

2. Если правила нет, добавьте:
   ```cmd
   netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
   ```

3. Проверьте что папка **dist** существует:
   ```cmd
   cd D:\BCS
   dir dist
   ```

4. Если папки нет, соберите проект:
   ```cmd
   npm run build
   ```

### Проблема: Ошибка "serve не найден"

**Решение:**

```cmd
npm install -g serve
```

## 📊 ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ

### Изменение пути к проекту

Если проект находится не в **D:\BCS**, отредактируйте файлы:

**start-server.bat:**
```batch
cd /d ПУТЬ\К\ПРОЕКТУ
```

**start-server-silent.vbs:**
```vbs
WshShell.Run "cmd /c cd /d ПУТЬ\К\ПРОЕКТУ && serve -s dist -l 3000", 0, False
```

**setup-autostart.bat:**
```batch
echo oLink.TargetPath = "ПУТЬ\К\ПРОЕКТУ\start-server-silent.vbs" >> %SCRIPT%
echo oLink.WorkingDirectory = "ПУТЬ\К\ПРОЕКТУ" >> %SCRIPT%
```

### Запуск с окном консоли (для отладки)

Если нужно видеть логи сервера, используйте:

```cmd
start-server.bat
```

Вместо скрытого запуска через **start-server-silent.vbs**
