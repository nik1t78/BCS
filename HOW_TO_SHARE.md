# 🚀 КАК СДЕЛАТЬ ЧТОБЫ ДРУГИЕ СОТРУДНИКИ МОГЛИ ПОЛЬЗОВАТЬСЯ

## 📋 Краткая инструкция (5 минут)

### Шаг 1: Запустите сервер

Откройте PowerShell в папке проекта и выполните:

```powershell
cd D:\BCS
npm install
npm run build
npm install -g serve
serve -s dist -l 3000
```

### Шаг 2: Откройте порт в firewall

Откройте PowerShell **от имени администратора**:

```powershell
netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
```

### Шаг 3: Узнайте IP адрес вашего компьютера

В PowerShell выполните:

```powershell
ipconfig
```

Найдите строку **"IPv4-адрес"** - это будет что-то вроде `192.168.1.100`

### Шаг 4: Создайте администратора

1. Откройте браузер и перейдите по адресу:
   ```
   http://192.168.1.100:3000
   ```
   (замените `192.168.1.100` на ваш IP адрес)

2. Зарегистрируйтесь с логином `admin` и паролем `admin123`

3. Нажмите **F12** (откроется консоль разработчика)

4. Перейдите на вкладку **Console**

5. Вставьте эту команду:

```javascript
const users = JSON.parse(localStorage.getItem('vks_users'));
const admin = users.find(u => u.login === 'admin');
admin.role = 'admin';
localStorage.setItem('vks_users', JSON.stringify(users));
location.reload();
```

6. Нажмите **Enter**

7. Готово! Теперь вы администратор!

### Шаг 5: Создайте пользователей для сотрудников

1. Войдите в систему как администратор
2. Перейдите в **"Админ-панель"**
3. Вкладка **"Пользователи"**
4. Нажмите **"Добавить пользователя"**
5. Заполните форму:
   - ФИО: Иванов Иван Иванович
   - Логин: ivanov
   - Пароль: Ivanov123!
   - Роль: user (или moderator)
   - Отдел: Разработка
6. Нажмите **"Создать"**

Повторите для всех сотрудников.

### Шаг 6: Отправьте доступы сотрудникам

Отправьте сотрудникам email:

```
Тема: Доступ к системе ВКС Расписание

Коллеги, добрый день!

Для планирования видеоконференций доступна новая система.

🔗 Адрес: http://192.168.1.100:3000

👤 Ваши данные для входа:
   Логин: [логин сотрудника]
   Пароль: [пароль сотрудника]

📖 Как пользоваться:
1. Откройте ссылку в браузере
2. Войдите с указанными данными
3. Перейдите в "Мои конференции"
4. Нажмите "Создать конференцию"
5. Заполните форму и выберите участников
6. Готово!

При возникновении вопросов обращайтесь к IT-отделу.

С уважением,
Администрация
```

## 🆘 Если что-то не работает

### Сотрудники не могут подключиться

**Проверьте:**
1. Сервер запущен? (должно быть окно PowerShell с `serve -s dist -l 3000`)
2. Firewall открыт? (выполните команду из Шага 2)
3. IP адрес правильный? (выполните `ipconfig` и проверьте)

**Решение:**
```powershell
# Проверьте что порт открыт
netsh advfirewall firewall show rule name="ВКС Расписание"

# Если не открыт, откройте снова
netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
```

### Сервер не запускается

**Ошибка:** "Port 3000 is already in use"

**Решение:**
```powershell
# Найдите процесс который занимает порт
netstat -ano | findstr :3000

# Убейте процесс (замените PID на номер из предыдущей команды)
taskkill /PID [номер] /F

# Запустите снова
serve -s dist -l 3000
```

### Потеряли доступ администратора

**Решение:**
```javascript
// В консоли браузера (F12):
const users = JSON.parse(localStorage.getItem('vks_users'));
const admin = users.find(u => u.login === 'admin');
admin.role = 'admin';
localStorage.setItem('vks_users', JSON.stringify(users));
location.reload();
```
