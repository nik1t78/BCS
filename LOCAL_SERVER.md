## 📝 ПОДРОБНАЯ ИНСТРУКЦИЯ

### 🔧 Шаг 1: Проверка установленных программ

Откройте командную строку и выполните:

```cmd
node --version
```

Должно показать: `v20.x.x` или выше

```cmd
npm --version
```

Должно показать: `10.x.x` или выше

```cmd
git --version
```

Должно показать: `git version 2.x.x`

**Если команды не работают** - установите программы из раздела "Что вам понадобится"

---

### 📂 Шаг 2: Переход в папку проекта

```cmd
cd D:\BCS
```

**Если папки нет**, создайте её:

```cmd
mkdir D:\BCS
cd D:\BCS
```

---

### 📦 Шаг 3: Установка зависимостей

```cmd
npm install
```

**Что происходит:**
- Скачиваются все необходимые библиотеки
- Создаётся папка `node_modules`
- Это занимает 2-5 минут

**Если возникла ошибка:**

```cmd
:: Очистите кэш npm
npm cache clean --force

:: Удалите старые файлы
rmdir /s /q node_modules
del package-lock.json

:: Установите заново
npm install
```

---

### 🏗️ Шаг 4: Сборка проекта

```cmd
npm run build
```

**Что происходит:**
- Проект компилируется в оптимизированную версию
- Создаётся папка `dist` с готовым сайтом
- Это занимает 10-30 секунд

**Должно появиться:**
```
✓ 41 modules transformed.
dist/index.html                   3.26 kB
dist/assets/index-xxx.css         46.44 kB
dist/assets/index-xxx.js          234.08 kB
✓ built in 1.75s
```

---

### 🌐 Шаг 5: Установка веб-сервера

```cmd
npm install -g serve
```

**Что происходит:**
- Устанавливается простой веб-сервер
- Он будет раздавать ваш сайт
- Это нужно сделать только один раз

**Если возникла ошибка прав доступа:**

Запустите командную строку **ОТ ИМЕНИ АДМИНИСТРАТОРА**:
1. Нажмите **Пуск**
2. Введите `cmd`
3. **Правый клик** на "Командная строка"
4. Выберите **"Запуск от имени администратора"**

---

### 🚀 Шаг 6: Запуск сервера

```cmd
serve -s dist -l 3000
```

**Что происходит:**
- Запускается веб-сервер на порту 3000
- Сайт становится доступен по адресу http://localhost:3000

**Должно появиться:**
```
   ┌────────────────────────────────────────────────────┐
   │                                                    │
   │   Serving!                                         │
   │                                                    │
   │   - Local:    http://localhost:3000                │
   │   - Network:  http://192.168.1.100:3000            │
   │                                                    │
   └────────────────────────────────────────────────────┘
```

**⚠️ ВАЖНО:** Не закрывайте это окно! Сервер работает пока окно открыто.

---

### 🌍 Шаг 7: Открытие сайта

Откройте браузер (Chrome, Firefox, Edge) и перейдите по адресу:

```
http://localhost:3000
```

**Должна открыться страница входа в систему!**

### 🔐 Шаг 8: Вход в систему

На странице входа введите:

- **Пароль:** `admin123`

## 🌐 ДОСТУП ДЛЯ ДРУГИХ КОМПЬЮТЕРОВ В СЕТИ

### Шаг 1: Узнайте IP адрес вашего компьютера

Откройте **НОВОЕ** окно командной строки и выполните:

```cmd
ipconfig
```

Найдите строку **"IPv4-адрес"**

Пример: `192.168.1.100`

---

### Шаг 2: Откройте порт в firewall

Запустите командную строку **ОТ ИМЕНИ АДМИНИСТРАТОРА**:

```cmd
netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
```

Должно появиться: **"ОК."**

---

### Шаг 3: Проверьте доступ

На **ДРУГОМ компьютере** в той же сети откройте браузер и перейдите:

```
http://192.168.1.100:3000
```

(замените `192.168.1.100` на ваш IP адрес)

**Должна открыться страница входа!**

## 🛠️ РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: "Port 3000 is already in use"

**Решение:**

```cmd
:: Найдите процесс который занимает порт
netstat -ano | findstr :3000

:: Убейте процесс (замените PID на номер из предыдущей команды)
taskkill /PID 12345 /F

:: Запустите сервер снова
serve -s dist -l 3000
```

---

### Проблема 2: "npm install" зависает или выдаёт ошибку

**Решение:**

```cmd
:: Очистите кэш npm
npm cache clean --force

:: Удалите старые файлы
rmdir /s /q node_modules
del package-lock.json

:: Установите заново
npm install
```

---

### Проблема 3: "npm run build" выдаёт ошибку

**Решение:**

```cmd
:: Обновите npm
npm install -g npm@latest

:: Удалите node_modules и package-lock.json
rmdir /s /q node_modules
del package-lock.json

:: Установите заново
npm install

:: Попробуйте собрать снова
npm run build
```

---

### Проблема 4: Сайт не открывается

**Решение:**

1. Проверьте что сервер запущен (окно командной строки открыто)
2. Проверьте адрес: `http://localhost:3000`
3. Попробуйте другой браузер
4. Очистите кэш браузера: **Ctrl + Shift + Delete**

---

### Проблема 5: Другие компьютеры не могут подключиться

**Решение:**

1. Проверьте что firewall открыт:
   ```cmd
   netsh advfirewall firewall show rule name="ВКС Расписание"
   ```

2. Проверьте IP адрес:
   ```cmd
   ipconfig
   ```

3. Проверьте доступность порта:
   ```cmd
   Test-NetConnection -ComputerName 192.168.1.100 -Port 3000
   ```

4. Убедитесь что все компьютеры в одной сети

---

### Проблема 6: "serve" не найден

**Решение:**

```cmd
npm install -g serve
```
