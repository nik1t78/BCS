## 🔐 Права доступа

### 👤 Обычный пользователь (user)
- Видит **ТОЛЬКО** свои конференции
- Видит конференции, где он участник
- Не видит другие конференции

### 🔧 Модератор (moderator)
- Видит **ВСЕ** конференции в системе
- Видит полную информацию о каждой конференции
- Видит место проведения (кабинет)
- Может редактировать конференции
- Может блокировать пользователей

### 👑 Администратор (admin)
- Видит **ВСЕ** конференции
- Полный доступ к админ-панели
- Может управлять пользователями
- Может менять пароли
- Может менять роли

## 🎯 Практические сценарии

### Сценарий 1: Модератор проверяет расписание

1. Открывает Dashboard
2. Видит блок "Следующая конференция" с полной информацией:
   - Название: "Еженедельный стендап"
   - Время: 10:00 - 10:30
   - **Место: Переговорная №1**
   - Организатор: Петрова М.В.
   - Участники: 5 чел.
3. Видит список всех конференций на сегодня
4. Может подключиться к любой конференции
5. Видит где проходит каждая ВКС (кабинет)

### Сценарий 2: Администратор управляет пользователями

1. Открывает Админ-панель
2. Переходит на вкладку "Пользователи"
3. Видит список всех пользователей
4. Может блокировать/разблокировать
5. Может менять роли
6. Может менять пароли

### Сценарий 3: Модератор проверяет заявку

1. Открывает Dashboard
2. Видит блок "Следующая конференция"
3. Проверяет:
   - ✅ Название корректное
   - ✅ Время указано правильно
   - ✅ **Место проведения: Переговорная №1**
   - ✅ Организатор указан
   - ✅ Участники добавлены
   - ✅ Описание заполнено
4. Если нужно, редактирует конференцию

## 🚀 Как использовать

### Для модераторов:

1. **Проверяйте расписание ежедневно**
   - Открывайте Dashboard утром
   - Проверяйте все конференции на сегодня
   - Убеждайтесь, что все кабинеты указаны

2. **Следите за приоритетами**
   - Конференции с высоким приоритетом отмечены 🔴
   - Проверяйте их в первую очередь

3. **Проверяйте места проведения**
   - Убеждайтесь, что кабинеты указаны корректно
   - Если указано "Онлайн" - проверяйте ссылки

4. **Используйте фильтры**
   - "Сегодня" - конференции на сегодня
   - "Ближайшие" - предстоящие конференции
   - "Все" - все конференции

### Для администраторов:

1. **Управляйте пользователями**
   - Создавайте новых пользователей
   - Блокируйте/разблокируйте
   - Меняйте роли
   - Сбрасывайте пароли

2. **Контролируйте конференции**
   - Видите все конференции
   - Можете редактировать любые
   - Можете удалять

3. **Следите за статистикой**
   - Проверяйте общую статистику
   - Анализируйте активность
