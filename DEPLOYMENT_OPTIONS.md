## 🐳 Вариант 1: Docker (РЕКОМЕНДУЕТСЯ)

### Преимущества:
✅ Все зависимости в контейнерах  
✅ Не нужно устанавливать Node.js, PHP, MySQL  
✅ Легко переносить между компьютерами  
✅ Готово к production  

### Быстрый запуск:

```bash
# 1. Запуск контейнеров
docker compose up -d --build

# 2. Инициализация БД
docker compose exec backend php artisan key:generate
docker compose exec backend php artisan migrate

# 3. Открыть http://localhost
```

📖 **Подробная инструкция:** [DOCKER_DEPLOYMENT.md](./DOCKER_DEPLOYMENT.md)  
📖 **Быстрый старт:** [DOCKER_QUICK_START.md](./DOCKER_QUICK_START.md)

## 💻 Вариант 2: Локально (Node.js)

### Преимущества:
✅ Быстрый запуск  
✅ Удобно для разработки  
✅ Не нужен Docker  

### Требования:
- Node.js 20+
- Git

### Быстрый запуск:

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка проекта
npm run build

# 3. Установка веб-сервера
npm install -g serve

# 4. Запуск сервера
serve -s dist -l 3000

# 5. Открыть http://localhost:3000
```

📖 **Подробная инструкция:** [LOCAL_SERVER.md](./LOCAL_SERVER.md)

## 🐧 Вариант 3: РЕД ОС

### Преимущества:
✅ Российская операционная система  
✅ Поддержка отечественного ПО  
✅ Безопасность  

### Требования:
- РЕД ОС 7.3+
- Docker или Node.js

### Быстрый запуск (через Docker):

```bash
# 1. Установка Docker
sudo yum install docker -y
sudo systemctl start docker

# 2. Запуск проекта
docker compose up -d --build

# 3. Инициализация БД
docker compose exec backend php artisan key:generate
docker compose exec backend php artisan migrate

# 4. Открытие порта
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --reload

# 5. Открыть http://localhost
```

📖 **Подробная инструкция:** [RED_OS_DEPLOYMENT.md](./RED_OS_DEPLOYMENT.md)  
📖 **Быстрый старт:** [RED_OS_QUICK_START.md](./RED_OS_QUICK_START.md)

## 📊 Сравнение вариантов

### Docker
```
✅ Плюсы:
   - Изолированная среда
   - Все зависимости включены
   - Легко масштабировать
   - Production-ready

❌ Минусы:
   - Требует Docker (500 MB)
   - Первый запуск дольше
   - Занимает больше места
```

### Локально
```
✅ Плюсы:
   - Быстрый запуск
   - Удобно для разработки
   - Меньше места на диске

❌ Минусы:
   - Нужно устанавливать Node.js
   - Зависимости на хост-машине
   - Сложнее переносить
```

### РЕД ОС
```
✅ Плюсы:
   - Российская ОС
   - Соответствие требованиям
   - Безопасность

❌ Минусы:
   - Нужно устанавливать зависимости
   - Настройка firewall
   - SELinux может блокировать
```
