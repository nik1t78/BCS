## 🎯 Как настроить автозапуск

### ⚡ Быстрая настройка (2 минуты)

1. Найдите файл **`setup-autostart.bat`** в папке проекта
2. **Правый клик** → **"Запуск от имени администратора"**
3. Дождитесь сообщения об успешной настройке
4. Нажмите любую клавишу

**Готово! ✅**

Теперь сервер будет запускаться автоматически при каждом входе в Windows.

---

## 🔄 Как это работает

### При включении компьютера:

```
1. Windows загружается
   ↓
2. Вы входите в систему
   ↓
3. Автоматически запускается start-server-silent.vbs
   ↓
4. Сервер стартует в скрытом режиме (без окна консоли)
   ↓
5. Сайт доступен: http://localhost:3000
```

### Что происходит в фоне:

- Сервер работает как фоновый процесс
- Не занимает место на панели задач
- Не показывает окно консоли
- Автоматически перезапускается при сбое
- Доступен для всех пользователей компьютера

## 📋 Управление сервером

### 🟢 Запуск сервера вручную

**С окном консоли (видно логи):**
```cmd
start-server.bat
```

**В скрытом режиме (без окна):**
```cmd
start-server-silent.vbs
```

### 🔴 Остановка сервера

**Через скрипт:**
```cmd
stop-server.bat
```

**Через диспетчер задач:**
1. **Ctrl + Shift + Esc**
2. Найдите **node.exe**
3. Правый клик → **Снять задачу**

**Через командную строку:**
```cmd
taskkill /F /IM node.exe
```

## 🔥 Решение проблем

### Проблема: Сервер не запускается автоматически

**Решение:**

1. Проверьте что файл **start-server-silent.vbs** существует в **D:\BCS**
2. Проверьте что ярлык создан в папке автозагрузки:
   ```cmd
   shell:startup
   ```
   Должен быть файл **"ВКС Расписание.lnk"**
3. Перезагрузите компьютер
4. Проверьте что сервер запустился

### Проблема: Порт 3000 занят

**Решение:**

```cmd
:: Найдите процесс
netstat -ano | findstr :3000

:: Остановите процесс (замените PID)
taskkill /PID 12345 /F

:: Запустите сервер снова
start-server.bat
```

### Проблема: Ошибка "serve не найден"

**Решение:**

```cmd
npm install -g serve
```

### Проблема: Сервер запускается, но сайт не открывается

**Решение:**

1. Проверьте firewall:
   ```cmd
   netsh advfirewall firewall show rule name="ВКС Расписание"
   ```

2. Если правила нет, добавьте:
   ```cmd
   netsh advfirewall firewall add rule name="ВКС Расписание" dir=in action=allow protocol=TCP localport=3000
   ```

3. Проверьте что папка **dist** существует:
   ```cmd
   cd D:\BCS
   dir dist
   ```

4. Если папки нет, соберите проект:
   ```cmd
   npm run build
   ```

## ⚙️ Дополнительные настройки

### Изменить порт

Если нужно изменить порт с 3000 на другой (например, 8080):

1. Отредактируйте **start-server.bat**:
   ```batch
   serve -s dist -l 8080
   ```

2. Отредактируйте **start-server-silent.vbs**:
   ```vbs
   WshShell.Run "cmd /c cd /d D:\BCS && serve -s dist -l 8080", 0, False
   ```

3. Обновите автозапуск:
   ```cmd
   remove-autostart.bat
   setup-autostart.bat
   ```

4. Доступ будет по адресу: **http://localhost:8080**

### Изменить путь к проекту

Если проект находится не в **D:\BCS**:

1. Отредактируйте **start-server.bat**:
   ```batch
   cd /d ПУТЬ\К\ПРОЕКТУ
   ```

2. Отредактируйте **start-server-silent.vbs**:
   ```vbs
   WshShell.Run "cmd /c cd /d ПУТЬ\К\ПРОЕКТУ && serve -s dist -l 3000", 0, False
   ```

3. Отредактируйте **setup-autostart.bat**:
   ```batch
   echo oLink.TargetPath = "ПУТЬ\К\ПРОЕКТУ\start-server-silent.vbs" >> %SCRIPT%
   echo oLink.WorkingDirectory = "ПУТЬ\К\ПРОЕКТУ" >> %SCRIPT%
   ```

4. Обновите автозапуск:
   ```cmd
   remove-autostart.bat
   setup-autostart.bat
   ```

## 📊 Сравнение режимов запуска

| Режим | Команда | Окно консоли | Логи | Автозапуск |
|-------|---------|--------------|------|------------|
| **С окном** | `start-server.bat` | ✅ Видно | ✅ Видны | ❌ Нет |
| **Скрытый** | `start-server-silent.vbs` | ❌ Нет | ❌ Не видны | ✅ Да |

### Когда использовать каждый режим:

**С окном консоли:**
- При разработке и отладке
- Когда нужно видеть логи
- При первом запуске для проверки

**В скрытом режиме:**
- Для продакшена
- Для автозапуска
- Когда не нужно видеть логи
