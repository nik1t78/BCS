## 👥 Как дать доступ другим пользователям

### Шаг 1: Узнайте IP адрес вашего компьютера

Откройте командную строку (Win+R → cmd → Enter) и выполните:

```cmd
ipconfig
```

Найдите строку **IPv4-адрес** (например: `10.48.4.235`)

### Шаг 2: Откройте порты в Firewall

Откройте PowerShell **от имени администратора** и выполните:

```powershell
netsh advfirewall firewall add rule name="VKS Frontend" dir=in action=allow protocol=TCP localport=5173
netsh advfirewall firewall add rule name="VKS API" dir=in action=allow protocol=TCP localport=8000
```

### Шаг 3: Измените URL API в коде

Откройте файл `src/api/client.ts` и измените:

```typescript
// Было:
const API_BASE_URL = 'http://localhost:8000/api';

// Стало (замените на ваш IP):
const API_BASE_URL = 'http://10.48.4.235:8000/api';
```

### Шаг 4: Пересоберите frontend

```powershell
npm run build
```

### Шаг 5: Дайте пользователям адрес

Отправьте им сообщение:

```
Здравствуйте!

Система ВКС Расписание доступна по адресу:
http://10.48.4.235:5173

Данные для входа:
- Логин: admin
- Пароль: admin123

При возникновении проблем обращайтесь к IT-отделу.
```

## 📋 Альтернатива: Автоматическое определение IP

Если хотите чтобы URL определялся автоматически, измените `src/api/client.ts`:

```typescript
// Автоматическое определение URL
const API_BASE_URL = `${window.location.protocol}//${window.location.hostname}:8000/api`;
```

Тогда пользователи смогут открывать сайт по любому адресу (localhost или IP), и API будет работать автоматически.

## 🛠️ Решение проблем

### Проблема: "Failed to fetch"

**Решение:**
1. Проверьте что Laravel API запущен:
   ```powershell
   docker compose ps backend
   ```
2. Проверьте что порт 8000 открыт:
   ```powershell
   netstat -ano | findstr :8000
   ```
3. Проверьте URL API в `src/api/client.ts`

### Проблема: Другие пользователи не могут подключиться

**Решение:**
1. Проверьте что порты открыты в Firewall
2. Проверьте что все в одной сети
3. Проверьте что IP адрес правильный
4. Попробуйте отключить Firewall временно для теста

### Проблема: API не отвечает

**Решение:**
```powershell
# Перезапустите backend
docker compose restart backend

# Проверьте логи
docker compose logs backend --tail=50
```
