# RSVP-напоминания участникам

Команда `php artisan meetings:send-rsvp-reminders` автоматически напоминает участникам, которые ещё не ответили на приглашение или выбрали «Под вопросом».

## Интервалы

В `backend/.env` можно указать интервалы в минутах до начала конференции через запятую:

```dotenv
RSVP_REMINDER_MINUTES=1440,60
```

По умолчанию отправляются напоминания за 24 часа и за 1 час. Значения принимаются в диапазоне от 1 до 10080 минут; дубликаты удаляются. Пустое значение отключает функцию:

```dotenv
RSVP_REMINDER_MINUTES=
```

После изменения переменной пересобрать конфигурационный кеш Laravel:

```powershell
docker compose exec backend php artisan config:clear
docker compose exec backend php artisan config:cache
```

## Правила отправки

- Получатели — только активные участники встречи, не включая организатора.
- Нет ответа и «Под вопросом» — напоминание отправляется.
- «Приду» и «Не приду» — напоминание не отправляется.
- Поддерживаются разовые и повторяющиеся встречи через общий `RecurrenceService`.
- Проверка выполняется планировщиком каждую минуту; небольшое запаздывание учитывается двухминутным окном.
- Повторные одинаковые уведомления для одной встречи, даты повторения и интервала блокируются проверкой существующих уведомлений.
- Уведомление появляется в центре уведомлений, всплывающих сообщениях и realtime SSE; при включённом MAX работает существующая доставка мессенджера.

## Проверка вручную

```powershell
docker compose exec backend php artisan meetings:send-rsvp-reminders
docker compose exec backend php artisan schedule:list
```

Никаких миграций не требуется. Таблицы и существующие данные не изменяются.
