# Автопилот ВКС-ссылок

Команда `vks:autopilot` запускается Laravel Scheduler раз в минуту.

## Поведение

- Проверка существующих SaluteJazz-ссылок выполняется для встреч в окне проверки.
- Автоматическое создание ссылок применяется только к будущим встречам со статусом `scheduled`.
- Встречи с прошедшей датой или временем не отправляются в очередь на создание новой комнаты.
- Если постановка задачи в очередь завершилась ошибкой, dedupe-lock не устанавливается: следующая итерация может повторить dispatch.
- Для массового импорта действует ограничение количества успешно поставленных задач за один проход.

## Настройка

`VKSBOT_AUTOPILOT_BATCH` — максимальное количество новых ссылок, отправляемых в очередь за одну итерацию. По умолчанию 50; допустимый диапазон 1–200.

Параметр уже проброшен через общий `backend-env` во все PHP-контейнеры. Чтобы изменить лимит, добавьте в корневой `.env`:

```dotenv
VKSBOT_AUTOPILOT_BATCH=50
```

Изменение этой настройки не требует миграций. После изменения пересоздайте PHP-контейнеры через `docker compose up -d` (без `-v`). Не устанавливайте чрезмерно большое значение: Selenium/SaluteJazz и очередь имеют ограниченную пропускную способность.

## Диагностика

```powershell
docker compose logs --tail=100 scheduler
docker compose logs --tail=100 queue
docker compose logs --tail=100 vks-bot
```

Если задача уже была создана, проверьте дневник ВКС-бота в админке и состояние очереди. Не очищайте таблицы `jobs` и `failed_jobs` вручную.
