# Точность аналитики загрузки

Phase 33 исправляет расчёт тепловой карты в административной панели.

## Что изменено

- Час считается занятым только если встреча действительно пересекает этот час. Например, встреча 10:00–11:00 занимает только слот 10:00, а не 11:00.
- Встреча 10:30–11:30 учитывается в слотах 10:00 и 11:00.
- Встречи через полночь распределяются между правильными днями недели.
- Некорректные и нулевые интервалы не искажают статистику.
- В выборку тепловой карты и исторических рейтингов не попадают будущие встречи.
- Отменённые встречи исключаются из исторического показателя прошедшего периода.
- Для совместимости сохранено поле API `total_meetings` (это число занятых часовых ячеек); дополнительно возвращается `meetings_count` — количество корректных записей встреч в выборке.

## Сохранность

Изменения не требуют миграций, не меняют встречи, пользователей, настройки, `.env` или Docker volumes. Административные маршруты и текущий интерфейс сохраняются.
