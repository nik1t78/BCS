# Подписка на календарь ВКС

## Что это даёт

В разделе «Главная» → «Мой календарь ВКС» пользователь может:
- скачать разовый файл `.ics`;
- создать персональную ссылку подписки для Outlook, Google Calendar, Apple Calendar и других календарей, поддерживающих iCalendar URL;
- скопировать ссылку и вставить её в функцию добавления календаря по URL;
- заменить ссылку (предыдущая немедленно перестаёт работать);
- отозвать ссылку, полностью отключив внешний доступ.

Календарь обновляется внешним приложением при очередном обращении к URL. Частота обновления зависит от самого приложения-календаря.

## Безопасность

- Для каждого пользователя существует не более одной активной ссылки.
- Ссылка содержит 64-символьный криптографически случайный токен.
- В базе данных хранится только SHA-256 хеш токена, а не исходный секрет.
- Публичный endpoint доступен только для чтения и ограничен rate limit.
- Внешняя ссылка показывает те же встречи, которые доступны пользователю: его собственные, встречи с его участием и публичные.
- Отключение или перевыпуск ссылки сразу делает предыдущую ссылку недействительной.
- Не публикуйте ссылку и не отправляйте её посторонним: любой обладатель ссылки может читать календарь.

## Обновление

Выполните обычное обновление приложения и примените аддитивную миграцию:

```powershell
docker compose exec backend php artisan migrate --force
docker compose exec backend php artisan optimize:clear
docker compose restart backend nginx
```

Миграция добавляет nullable-столбец `calendar_token_hash` в `user_settings`. Существующие настройки и встречи не изменяются. Откат миграции удаляет только этот новый столбец.

## API

- `GET /api/schedule.ics` — прежний авторизованный разовый экспорт.
- `GET /api/calendar-feed/status` — статус активной подписки (авторизация обязательна).
- `POST /api/calendar-feed/rotate` — выпустить новую ссылку (авторизация обязательна).
- `DELETE /api/calendar-feed` — отозвать ссылку (авторизация обязательна).
- `GET /api/calendar-feed/{token}.ics` — публичная read-only подписка по секретному токену.
