# Безопасность экранов переговорных

Phase 34 исправляет выдачу расписания на публичные экраны залов.

## Что исправлено

- Приватные встречи исключаются из обоих публичных API экранов переговорных. Их названия и ссылки подключения не передаются на телевизор.
- В выборку «ближайшей встречи» теперь попадают активные повторяющиеся серии, созданные ранее сегодняшнего дня, если они ещё не завершены.
- Для повторяющихся встреч выбирается ближайшее событие, которое ещё не закончилось. Если сегодняшнее событие уже прошло, экран показывает следующее, а не скрывает всю серию.
- Учитывается дата окончания повторения и 92-дневный горизонт сервиса повторов.
- Выбор следующего события вынесен в отдельную политику с регрессионными smoke-тестами.

## Сохранность

Без миграций и изменений БД, токенов залов, настроек, `.env` и Docker volumes. Публичные экраны сохраняют прежний URL и формат ответа; приватные встречи намеренно не отображаются.
