# Подбор общего свободного времени

Функция добавляет в раздел «Расписание» кнопку «Подобрать время».

## Как работает

- Пользователь задаёт диапазон до 15 календарных дней и длительность встречи (15–480 минут).
- Можно выбрать сотрудников; время текущего пользователя учитывается автоматически.
- Сервер проверяет занятость выбранных участников и всех активных переговорных.
- Учитываются повторяющиеся встречи и индивидуальный график залов, включая закрытые дни.
- Предлагаются интервалы с шагом 30 минут.
- В ответе нет названий чужих встреч, описаний, ссылок, логинов или других деталей — только свободный интервал и название зала.
- Нажатие «Выбрать время» открывает существующую форму создания конференции с предзаполненными залом, датой и временем.

## API

Авторизованный POST `/api/meetings/suggest-slots`:

```json
{
  "date_from": "2026-11-24",
  "date_to": "2026-11-30",
  "duration": 60,
  "participant_ids": [12, 18],
  "limit": 20
}
```

Поля:
- `date_from`, `date_to` — обязательные даты в формате YYYY-MM-DD; диапазон не более 15 дней.
- `duration` — обязательная длительность в минутах, 15–480.
- `participant_ids` — массив до 100 идентификаторов активных пользователей; текущий пользователь добавляется сервером автоматически.
- `room_id` — необязательное ограничение конкретным активным залом.
- `exclude_meeting_id` — необязательное исключение редактируемой встречи.
- `limit` — необязательное число результатов, 1–40.

Endpoint ограничен отдельным rate limit. В ответе выдаются только свободные слоты. Изменений БД и миграций нет.
