# Экспорт аналитики ВКС

На странице «Статистика» доступны два способа сохранить отчёт: «Скачать отчёт Excel» и «Печать / сохранить PDF» (через стандартное окно печати браузера).

Книга содержит четыре листа:
- **Показатели** — сводные показатели конференций и активности пользователя.
- **Динамика** — число конференций по дням за последние 14 дней и по неделям за последние 8 недель.
- **Залы** — наиболее используемые переговорные.
- **Организаторы** — рейтинг организаторов в пределах данных, доступных текущему пользователю.

Отчёт формируется в браузере из уже загруженных и отфильтрованных по правам данных. ExcelJS загружается динамически при нажатии кнопки, поэтому экспорт не увеличивает стартовую загрузку приложения. PDF формируется средствами браузера через печать; для него используется отдельная область `.print-area`, которая скрывает остальной интерфейс и элементы управления. Новых API, миграций и изменений БД не требуется.
